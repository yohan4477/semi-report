# DCF 내재가치 188만원, 주가보다 14.3% 위 - SK하이닉스

> 출처: 네이버 프리미엄 「SK Hynix의 DCF에 의한 주식가치 평가」(엘곰), 2026-08-17. 유료 구독 글을 요약했다. SemiAnalysis 코퍼스와 별개의 제3자 해설이니 투자 판단 근거로 쓰지 말 것.

## 한 줄 요약

회계사 필명 엘곰이 SK하이닉스(000660)를 DCF(현금흐름할인법, 앞으로 벌어들일 현금을 지금 값으로 당겨 더하는 평가)로 계산해 주당 내재가치 1,880,300원을 냈다. 2026년 8월 14일 종가 1,645,000원보다 14.3% 높다. 결론을 만든 것은 할인율이 아니라 앞 5년의 마진 가정이다 — 영업이익률 70%대 후반이 곧바로 꺾이지 않고 완만히 내려온다고 두었다.

## 핵심 포인트

### 어떤 회사로 놓고 계산했나

SK하이닉스는 D램과 낸드플래시를 만드는 종합 메모리 반도체 회사이고, AI 서버에 들어가는 HBM(고대역폭메모리, D램을 여러 층 쌓아 데이터 통로를 넓힌 메모리)에서 앞서 있다. 2023년 다운사이클에서 대규모 영업손실을 낸 뒤 2024~2025년 AI 데이터센터 투자가 늘며 영업이익률이 사상 최고 수준까지 올라왔고, 2026년 반기 실적도 역대 최대를 다시 썼다.

필자는 여기서 전통적인 반도체 사이클을 그대로 적용하지 않았다. HBM은 공급사가 몇 곳뿐인 과점 구조이고 고객사와 다년 계약을 맺어 팔기 때문에, 범용 D램보다 가격이 덜 흔들리고 수요가 구조적으로 늘어나는 국면이라고 봤다. 그래서 추정 앞부분은 고마진을 유지하고 뒤로 갈수록 완만히 정상화되는 경로로 설계했다.

### 현금흐름을 어떻게 깔았나

- T1~T3(첫 3년)는 증권사 컨센서스(추정치 평균)를 그대로 썼다.
- T4부터는 컨센서스가 없다. T3의 매출성장률 8%와 이어지도록 성장률을 10%에서 3%까지 낮추고, 영업이익률은 65%에서 30%까지 점진적으로 수렴시켰다.

### 할인율(WACC)은 13.36%

WACC(가중평균자본비용, 주주와 채권자가 요구하는 수익률을 자본 구성비로 섞은 값)를 이렇게 잡았다.

| 구성요소 | 적용값 | 비고 |
|---|---|---|
| Rf(국고채 10년) | 4.30% | 2026.08.14 기준 |
| β(조정베타, 2년) | 1.5465 | 첨부 자료 |
| MRP(시장위험프리미엄) | 6.0% | 5.0~6.5% 중간값 |
| Ke(자기자본비용) | 13.58% | 4.30% + 1.5465 × 6.0% |
| Kd(세후 타인자본비용) | 2.80% | 이자비용/이자부부채 기준, 세율 25% |
| D/(D+E) | 2.02% | 시가총액 기준 |
| **WACC** | **13.36%** | |

빚이 자본에서 차지하는 몫이 2.02%뿐이라 WACC가 사실상 자기자본비용을 따라간다.

### 내재가치 1,880,300원

영구성장률(g, 추정 기간이 끝난 뒤에도 계속 자란다고 보는 속도)은 2.5%로 뒀다.

| 항목 | 값 |
|---|---|
| PV(FCF, T1~T10) | 1,031.93조원 |
| PV(Terminal Value) | 278.32조원 |
| 총 영업가치(EV) | 1,310.25조원 |
| 순차입금(순현금) | -63.20조원 |
| 주주지분가치 | 1,373.45조원 |
| 발행주식수 | 730,492,365주 |
| 주당 내재가치 | 1,880,300원 |
| 현재 주가(2026.08.14) | 1,645,000원 |
| 괴리율 | +14.3% |

### 결론을 흔드는 것은 할인율이 아니다

민감도 분석(WACC와 g를 위아래로 흔들어 결과가 얼마나 바뀌는지 보는 것)에서 가장 보수적인 조합인 WACC 14.36%·g 1.5%에서도 주당가치는 1,741,000원으로 현재 주가보다 높다. 즉 할인율과 영구성장률만 조정해서는 결론이 뒤집히지 않는다. 밸류에이션은 T1~T5 구간의 이익 수준 가정에 훨씬 민감하다.

### 필자가 스스로 밝힌 취약점

- T4~T5에서 영업이익률을 65%, 55%로 유지한 것은 메모리 반도체 역사에서 전례가 드문 고마진이 상당 기간 이어진다는 전제다. 삼성전자·마이크론이 HBM에서 따라붙는 속도나 고객사와의 협상력이 바뀌어 이 구간 마진이 더 빨리 내려오면 내재가치는 상당폭 낮아진다.
- 추정 기간 전체에 걸쳐 전통적 반도체 사이클의 급격한 가격 붕괴 구간을 넣지 않았다. 공급 과잉으로 다운사이클이 다시 오면 실제 현금흐름은 이 경로를 크게 밑돈다.
- 그래서 필자의 결론은 "현재 주가는 HBM 주도의 실적 슈퍼사이클이 앞으로 수년간 큰 조정 없이 이어진다는 시나리오를 이미 상당폭 반영하고 있고, 이 가정 경로를 유지하는 한 지금 주가가 과도하게 높지는 않다"는 것이다. 전통적 사이클 회귀 가능성을 뺀 결과라는 단서를 스스로 달았다.

### 다른 계산과 비교

같은 종목을 밸류에이션 서비스 Simply Wall St는 적정주가 5,583,125원으로 평가했다. 필자는 이 숫자에 대해 "이건 뭔가 싶다"고만 적었다.
