# 성공한 작업당 비용이 새 지표가 된다 — 모델 라우팅 수혜주 3종

> 출처: 미국주식 사관학교 카레라(네이버 프리미엄 텍스트), 2026-07-31. 유료 구독 원문의 **요약**이며 전문 재수록이 아님. SemiAnalysis 코퍼스와 별개의 제3자 해설로, 투자 판단 근거로 쓰지 말 것.

## 한 줄 요약
토큰 단가는 3년 만에 1,000분의 1로 떨어졌는데 "일 하나를 제대로 끝내는 값"은 그만큼 안 떨어졌다 — 그래서 어떤 AI를 만드느냐보다 싸진 AI를 골라 쓰는 장치(모델 라우팅)를 쥔 회사가 유리해지고, 필자는 클라우드플레어·스노우플레이크·데이터독을 그 자리로 꼽는다.

## 핵심 포인트
- **성능 지표가 칩에서 작업으로 옮겨간다.** 예전엔 무어의 법칙 곡선 하나로 컴퓨터 발전을 예측했는데, AI 성능은 실리콘·아키텍처·소프트웨어·데이터 네 군데서 나오고 각자 다른 속도로 움직인다. 카탈로그 스펙으로는 비교가 안 된다 — H100·H200보다 못한 GPU를 쓴 중국 AI가 비슷한 성능을 내는 게 그 증거다.
- **업계가 그 대신 쓰는 말.** OpenAI는 "성공한 작업당 비용(Cost per Successful Task)", 엔비디아는 "달러당 지능(Intelligence per Dollar)". 받아들일 만한 품질로 유용한 작업 하나를 끝내는 데 드는 총비용을 센다.
- **토큰이 싸다고 AI가 싼 게 아니다.** 싼 모델에 코드를 시켰다가 세 번 다시 시키고 사람이 붙어 고치면, 한 번에 끝낸 비싼 모델이 총비용에서 더 싸다.
- **실제로 역전이 나온다.** Claude Sonnet 5는 토큰 단가가 상위 모델 Opus 4.8보다 40%가량 싼데, 벤치마크 한 세트를 끝까지 돌려보니 작업당 2.29달러로 Opus 4.8의 1.99달러보다 비쌌다. 토큰 효율이 좋아진 만큼 더 크고 더 길게 생각시키는 쪽으로 수요가 옮겨가 상쇄해버린다.
- **그래서 갈아끼울 수 있느냐가 갈린다.** 최상위 모델 하나에 묶인 회사는 모든 요청에 계속 최상위 가격을 낸다. 제품 밑의 모델을 바꿔 낄 수 있는 회사는 가격 인하가 나올 때마다 즉시 흡수한다. 쉬운 건 싼 모델로, 어려운 건 비싼 모델로 넘기는 게 모델 라우팅이고, 지금 AI 원가를 낮추는 가장 강한 장치다.
- **다만 각 회사가 실제로 어떻게 라우팅하는지는 알 수 없다** — 최고 기밀이다. 그래서 필자는 라우팅 자체를 파는 쪽을 본다.

## 필자가 꼽은 3종과 각자의 자리
| 회사 | 티커 | 하는 일 | 필자의 비유 |
|---|---|---|---|
| 클라우드플레어 | NET | AI Gateway — 여러 모델·공급자를 한 관문으로. 2026년 도입된 Dynamic Routing이 요청 조건·사용자 등급·예산 한도로 모델을 고르고, 오류 나면 다른 모델로 넘김 | 교통정리 |
| 스노우플레이크 | SNOW | Cortex AI·Cortex AI Function Studio, AISQL의 adaptive model cascade — 싼 모델로 먼저 처리하고 확신이 부족할 때만 강한 모델로 올림 | 스스로 빠른 길 찾는 택시기사 |
| 데이터독 | DDOG | Agent Observability — 모델별 호출 수·지연·오류·토큰 소비·추정 비용 추적. 라우팅이 되려면 먼저 측정이 돼야 한다 | 혼잡 통행료 걷는 쪽 |

## 주요 숫자
| 수치 | 의미 |
|---|---|
| 30 / 60달러 | 2023년 3월 GPT-4 등장 시 100만 토큰 입력/출력 단가 |
| 0.5달러 미만 | 3년 뒤 같은 GPT-4급 성능의 100만 토큰 단가 |
| 약 95% / 약 1,000분의 1 | 2년 / 3년 기준 토큰 단가 하락폭 |
| 40% | Claude Sonnet 5가 Opus 4.8보다 싼 토큰 단가 |
| 2.29 vs 1.99달러 | 같은 벤치마크 세트의 작업당 실제 비용(Sonnet 5 vs Opus 4.8) — 역전 |
| 90~95% 품질 · 2~6배 속도 | adaptive model cascade 관련 연구가 제시한 결과 |
| 4 | AI 성능을 정하는 요소 수(실리콘·아키텍처·소프트웨어·데이터) |

## 비유 · 표현
- **"교통정리 → 택시기사 → 통행료"** — 라우팅 밸류체인에서 세 회사가 서로 다른 자리에 선다는 정리.
- **"돈 좀 더 내도 되니까 제발 한 번에 제대로 했으면"** — 성공한 작업당 비용을 한 문장으로 옮긴 것.
- **"꼽사리를 끼기 시작한다"** — 실리콘 혼자였던 성능 곡선에 아키텍처·서빙·데이터가 끼어든 상황.

## 유보 사항
- 클라우드플레어 매출에서 AI Gateway 비중은 공개되지 않아, 신고가인 현 주가에 얼마나 반영됐는지 필자도 모른다고 밝힌다.
- 데이터독은 모델 라우팅의 직접 수혜 정도가 나머지 둘보다 약하다고 필자가 스스로 단서를 단다.
- 3사 모두 원래 다른 논리로 다뤄지던 종목이고, 이 글은 "성공한 작업당 비용"이라는 새 관점을 덧댄 것이다.
