# Action Data Scaling 문제

> 출처: sudoremove.com 박종현(공개 웹 에세이 · fundamentals 시리즈 4/4), 2026-03-19. 원문의 **요약**이며 전문 재수록이 아님. 원문 https://sudoremove.com/knowledge/essays/fundamentals/scaling-problem/ · SemiAnalysis 코퍼스와 별개의 제3자 해설로, 투자 판단 근거로 쓰지 말 것.

## 한 줄 요약
VLA가 LLM처럼 규모를 키워 성능을 얻는 길을 그대로 못 밟는 이유를 데이터·평가·기술 셋으로 나누고, 이를 뚫으려는 수집 경로 다섯 가지를 늘어놓되 아직 어느 쪽도 정답으로 판명되지 않았다고 결론짓는다.

## 핵심 포인트
- **막는 것 ①: 데이터가 없다.** 행동 데이터(Action Data)는 인터넷에 존재하지 않는다. 텍스트처럼 이미 쌓여 있는 것을 긁어오는 방식이 통하지 않고 물리적으로 직접 모아야 한다.
- **막는 것 ②: 평가가 비싸다.** 실물 로봇을 돌려야 성능을 알 수 있다. 하드웨어가 부서질 위험 때문에 자동 벤치마크를 돌릴 수 없고, 이것이 개발 반복 속도를 직접 깎는다.
- **막는 것 ③: 기술이 덜 됐다.** 촉각 센싱 구현, 손처럼 정교한 하드웨어 제조, 물리적 지능에 대한 이해 자체가 아직 부족하다.
- **경로 ①: 텔레오퍼레이션(원격 조작).** 사람이 직접 조종해 데이터를 만든다. 테슬라는 옵티머스 학습용 조작자를 시급 48달러에 뽑았고, 키 170~180cm·하루 7시간 이상 보행·13kg(30파운드) 운반이라는 신체 조건을 걸었다. VR 장비를 오래 쓰면 심한 피로와 멀미가 와서 조작자의 지속 시간이 한계다.
- **경로 ②: UMI(Universal Manipulation Interface).** 로봇 없이 사람이 들고 다니는 집게로 조작 데이터를 모으고, 그 데이터를 다른 로봇 플랫폼으로 옮긴다.
- **경로 ③: 시뮬레이션.** 엔비디아 Isaac GR00T가 합성 데이터를 만든다. 시뮬레이션과 현실의 차이(sim-to-real gap)를 메우는 것이 관건이다.
- **경로 ④: 커뮤니티.** HuggingFace가 하드웨어·소프트웨어를 오픈소스로 풀고 데이터·모델을 한곳에 모으는 방식. SmolVLA가 그 가능성의 증거다. ALOHA도 오픈소스로 공개돼 연구 진입 장벽을 낮췄다.
- **경로 ⑤: 월드모델 + IDM.** 1X Technologies가 레이블 없는 영상에서 행동을 역으로 뽑아낸다. IDM(Inverse Dynamics Model, 역동역학 모델)으로 자기지도 학습을 걸어, 인터넷에 무한히 쌓인 사람 행동 영상을 데이터원으로 바꾸려는 시도다.
- **결론은 미정.** 다섯 경로 중 어느 것도 스케일 문제를 푼다고 입증되지 않았다.

## 주요 숫자
| 수치 | 의미 |
|---|---|
| 48달러/시간 | 테슬라 옵티머스 학습용 원격 조작자 시급 |
| 170~180cm · 7시간 · 13kg | 조작자 신체 조건(키 · 하루 보행 · 운반 중량) |

## LLM과 VLA의 대조
| | LLM | VLA |
|---|---|---|
| 데이터원 | 인터넷(사실상 무한) | 실물 로봇 동작(제한) |
| 수집 비용 | 낮음 | 높음 |
| 평가 | 자동 | 실물 로봇 필요 |

## 비유 · 표현
- **'인터넷에 없는 데이터'**. LLM의 성공 공식이 로봇에 그대로 복사되지 않는 이유를 한마디로 못 박는 표현.
