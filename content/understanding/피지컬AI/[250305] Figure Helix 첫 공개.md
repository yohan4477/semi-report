# [250305] Figure Helix 첫 공개

> 출처: sudoremove 유튜브 「휴머노이드의 시작 Figure AI Helix, VLA」(2025-03-05, 22분, 진행 JB·JC). 자동 자막 전문을 **요약**한 것이며 전문 재수록이 아니다. 원문 https://youtu.be/zB2n1vWSxYM · SemiAnalysis 코퍼스와 별개의 제3자 해설이고, 투자 판단 근거로 쓰지 말 것.

## 한 줄 요약

Figure AI가 VLA(Vision-Language-Action, 시각·언어·행동 통합 모델)인 Helix를 처음 공개했다. 이전 VLA가 그리퍼 위치만 다루던 것과 달리 손가락 다섯 개·손목·머리·몸통까지 35 자유도를 신경망 하나로 구동한 첫 사례이고, 판단을 맡는 System 2와 반사를 맡는 System 1로 나눈 구조를 처음 밝혔다. Figure AI는 오픈AI와 결별한 직후 이 모델을 공개했고, 로봇 하드웨어뿐 아니라 모델도 자체 제작했다고 강조한다. 학습 데이터는 텔레오퍼레이션(teleoperation, 사람이 로봇을 원격 조작해 움직임을 그대로 따라 하게 만드는 방식)으로 약 500시간을 모은 뒤 VLM으로 자동 라벨링했다고 진행자들은 추정한다.

## VLA로 무엇이 처음 됐나

- **자유도 35개.** 이전 VLA는 그리퍼 위치(XYZ 3개, 피치·롤·요 3개, 그리퍼 여닫음 1개, 합쳐 7 자유도)만 다뤘다. Helix는 손가락 다섯 개씩·손목·머리·몸통까지 35 자유도를 한 번에 낸다.
- **꽃게발에서 사람 손으로.** 그 전 데모는 진행자 표현으로 "꽃게발"처럼 집게 위치만 옮기는 수준이었는데, Helix는 상체 전신을 사람처럼 정밀하게 구동한 첫 사례라고 진행자들은 짚는다.
- **고전 제어 없이 신경망 하나로.** 로봇 정책을 최적화 문제로 푸는 고전 제어(보스턴 다이내믹스 아틀라스가 쓰는 방식)를 쓰지 않고, Helix는 신경망만으로 구동한다. 신경망 제어는 레이턴시가 높아 느리다고 알려져 왔는데 실제로 돌아간 것에 진행자들은 놀란다.
- **저전력 임베디드 GPU.** 어떤 칩인지 공식 공개는 없었지만, 진행자들은 Figure AI가 엔비디아와 시뮬레이션 학습으로 협력해온 점을 근거로 엔비디아 오린(Orin) 계열로 추정한다.

## System 2·System 1 이원 구조

- **System 2 = 판단.** 7B급(진행자는 처음 8B로 언급) VLM이 이미지·명령·조인트 각도(로봇 자신의 몸 상태)를 입력받아 판단하고, 결과를 레이턴트 벡터(latent vector, 신경망 내부의 압축된 표현 값)로 System 1에 전달한다. 7~9Hz로 느리게 돈다.
- **System 1 = 반사.** 크로스 어텐션 인코더-디코더 구조의 비전 모터 트랜스포머가 System 2의 레이턴트 벡터·이미지·상태를 받아 200Hz로 빠르게 액션을 낸다. 진행자들은 척추 반사(생각 없이 즉각 나가는 반응)에 비유한다.
- **S1도 가볍게 유지한다.** 진행자들은 Physical Intelligence의 π0(파이제로) 액션 익스퍼트가 300M 안팎으로 가벼운 것처럼, Helix의 System 1도 비슷하게 가볍게 만들어 액션을 빠르게 낸다고 짚는다.
- **비동기 학습.** 두 신경망은 동기화되지 않고 따로 도는데, System 2가 판단을 내릴 때쯤 로봇 상태가 이미 바뀌어 있을 수 있어 두 시스템 사이에 시간적 오프셋(포지셔널 임베딩과 비슷한 개념)을 넣어 학습했다고 진행자들은 설명한다. 정확히 왜 필요한지는 회사가 자세히 공개하지 않아 진행자들도 확신하지 못한다.
- **GPU 두 개로 분리 구동.** 느린 System 2와 빠른 System 1을 GPU 두 개에 나눠 돌리는 것으로 진행자들은 추정하며, 이 하드웨어·아키텍처 설계를 근거로 "데모만 있고 실체가 없다"는 기존 의심을 접는다.

## 오픈AI 결별과 자체 모델

- **이전 데모는 오픈AI 모델이었다.** Figure AI가 앞서 화제가 된 사과 집기 데모는 오픈AI의 스피치-투-텍스트·리얼타임 API와 펑션 콜링으로 계획을 세운 것으로, 테크니컬 페이퍼도 없이 오픈AI 모델을 로봇에 붙인 수준이라고 진행자들은 비판적으로 봤었다.
- **Helix는 자체 개발이다.** 오픈AI와 결별한 직후 공개된 Helix는 로봇 하드웨어뿐 아니라 VLA 모델까지 Figure AI가 직접 만들었다.
- **π0 대비 자체 스택을 강조한다.** π0는 VLM 3B에 다양한 몸체(오픈 X-임베디먼트 데이터셋 등 여러 로봇의 데이터를 모은 것)에서 두루 되는 범용성을 추구하는 반면, Helix는 VLM 7B급을 자기 하드웨어 하나에 최적화해 35 자유도까지 끌어올렸다고 대비한다.

## 학습 데이터

- **텔레오퍼레이션 약 500시간.** 학습 데이터는 사람이 텔레오퍼레이션으로 로봇을 조작해 모은 약 500시간 분량으로 진행자들은 추정한다.
- **VLM으로 자동 라벨링.** 사람이 직접 지시문을 붙이는 대신, System 2의 VLM으로 로봇 카메라 영상을 보고 "이 동작을 만들려면 어떤 지시를 했을까"를 추론해 인스트럭션을 자동 생성했을 것으로 진행자들은 추정한다.

## π0와 Helix 비교

| | 이전 그리퍼형 VLA | π0(Physical Intelligence) | Helix(Figure AI) |
|---|---|---|---|
| 제어 자유도 | 7(XYZ 3 + 피치·롤·요 3 + 그리퍼 1) | 7~18(로봇마다 다름) | 35 |
| VLM 크기 | - | 3B | 7B(진행자는 처음 8B로도 언급) |
| 지향점 | - | 다양한 몸체에 두루 통함 | 자기 하드웨어 하나에 최적화 |

## 진행자들이 유보한 것

- 어떤 GPU에서 도는지 공식 공개가 없어 엔비디아 오린 계열이라는 것은 추정이다.
- 시간적 오프셋을 왜 넣었는지 회사가 자세히 공개하지 않아 정확한 이유를 모른다고 밝힌다.
- 학습 데이터 500시간, GPU 두 개 분리 구동, S1 파라미터 규모는 모두 진행자들의 추정이고 회사가 수치를 공개한 것이 아니다.

## 곁가지

- 휴머노이드 형태가 정말 최선인지 회의하며 손가락 개수·바퀴 대안 등을 나눈다.
- 일런 머스크의 "사람을 대체하려면 폼팩터도 사람과 같아야 한다"는 주장을 인용한다.
- 전기 모터 구동 로봇이 무거운 힘을 요구하는 작업(사람을 들어올리기, 고기 썰기)은 아직 못 한다는 한계를 지적한다.
- Helix 공개가 근미래 시장성보다는 인재 채용·데이터 수집 확대를 노린 행보라는 냉소적 평가를 남긴다.
- Figure AI가 BMW와 협업하고 있다는 언급이 나온다.
