# 통합 보고서 층 — 새 세션 시작 프롬프트 (본보기)

2026-09-05 선단 패키징 층(`sec-pkg`)을 세운 뒤 만들었다. 그 전에 쓰던
`_prompt_packaging.md` 는 재료 열두 개 경로·함정 넷·검사기 목록·위임 규칙을 전부 손으로
적어야 했다. 지금은 그게 다 스킬과 규칙 문서에 들어가 있어서 **주제만 적으면 된다.**

---

## 붙일 것 (이게 전부다)

```
「<주제>」로 통합 보고서 층을 한 편 쓴다. insight-report 스킬을 따른다.
재료 후보를 먼저 보여 주고, 내가 자르라고 하면 그때 진행해.
```

두 번째 줄이 있어야 재료를 정하기 전에 한 번 멈춘다. 그 확인이 필요 없으면 빼도 된다.

## 붙이면 더 나은 것 (있으면 적고, 없으면 안 적어도 된다)

```
주제 낱말   find_materials 에 넣을 말. 안 적으면 내가 지어낸다. 영문 클리핑까지
            보려면 영문도 같이 — 「패키징 인터포저 CoWoS EMIB packaging interposer」
넘길 것     옆 층이 이미 다룬 대목. 「광학은 보고서 ⑥이 맡으니 넘겨」처럼.
            안 적으면 기존 층을 내가 읽고 겹치는 데를 찾는다
기간        「2025년 이후만」 같은 자름. 안 적으면 코퍼스에 있는 대로 쓴다
길이        기본은 CPO·선단 패키징 급(절 열둘에서 열넷, 2만 5천 자 안팎).
            짧게 가려면 「절 일곱쯤」처럼 적는다
```

## 안 적어도 되는 것 — 이미 어딘가에 있다

```
본보기        insight-report 가 sec-pkg 를 가리킨다
재료 찾기     scripts/find_materials.py. 스킬 경로의 0단계
절 구성       스킬의 「절을 세우는 법」과 doc-structure
차례·번호     scratchpad/_rep_toc.py 가 붙이고 check_toc 가 문다
도해 규칙     insight-figure 와 확정 규칙 §3. 부품은 _pkg_fig 를 본다
위임문        insight-report/references/위임문.md 에 두 벌
검사기 목록   CLAUDE.md. 전부 돌린다
전수          check_cover 가 labels 와 인용을 맞춰 본다
커밋·푸시     의미 단위마다. 승인 안 묻는다
```

## 나오는 것

```

```

## 어디서 멈춰 물을까

기본은 재료를 자를 때 한 번이다. 나머지는 안 묻고 간다(CLAUDE.md 「단계마다 승인 묻지
않는다」). 다만 아래 셋이 나오면 그때는 멈추고 묻는 편이 낫다.

```
재료가 넷 아래   층 하나로 세울 만한 두께가 안 나온다. 주제를 넓힐지 물어야 한다
옆 층과 절반 겹침 넘길 것을 정하지 않으면 같은 말을 두 층이 한다
원문이 서로 어긋남 어느 쪽을 앞세울지가 판단이라 밝히고 간다. 이번엔 InFO 매출이 그랬다
```
