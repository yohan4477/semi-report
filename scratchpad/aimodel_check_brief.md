# 원문 대조 위임 — AI 모델 층 (공통 지시)

저장소 루트: C:\Users\y\semianalysis

초안 하나를 **원문과 줄 단위로 대조**한다. 글을 고치는 일이 아니라 어긋난 데를 찾아 목록으로 내는 일이다.

## 대조할 초안
`insights/reports/aimodel-2026-10-02.md`

문장과 표 칸은 끝에 `(라벨 L줄번호)` 를 달고 있다. 한 괄호에 라벨이 여럿이면 쉼표로 나뉜다 — `(KIMI L405, DSV4 L100)`.
**네가 맡는 라벨은 위임문에 적힌 것뿐이다.** 다른 라벨이 붙은 인용은 건너뛴다.

라벨과 원문 파일의 짝은 `scratchpad/aimodel_materials.tsv` (둘째 칸 라벨, 셋째 칸 경로). 원문은 전부 영문 클리핑이다.

## 하는 일
맡은 라벨의 인용을 전부 찾아, 원문의 해당 줄을 Read(offset/limit) 로 열어 넷을 본다.

1. **값** — 숫자·단위·범위가 그 줄(또는 범위)에 있나. 반올림·환산·범위 바꿔치기가 있나
2. **귀속** — 누가 한 말인가. 회사 발표를 저자 판단으로, 저자 추정을 공표로 바꾸지 않았나. 표의 「성격」 칸도 본다
3. **유보** — 원문의 단서(we think, likely, reportedly, suspect, may)를 단정으로 바꾸지 않았나
4. **줄 번호** — 그 줄에 그 내용이 있나. 없으면 ±5줄을 찾아 맞는 번호를 댄다

초안은 한국어로 옮겨 쓴 글이다. 영어 구절이 그대로 없어도 뜻이 같으면 일치다.

## 산출 형식
위임문에 적힌 파일 하나로 쓴다. 초안 파일은 **고치지 마라.**

```
## 요약
- 확인한 인용 N / 일치 N / 어긋남 N / 줄 번호 틀림 N / 원문 밖 N

## 어긋난 것
- [라벨 L95] 초안: "…" / 원문: "…" / 무엇이 다른가: 값·귀속·유보·줄번호 중 무엇 / 고칠 안: "…"
```

규칙 — 반드시 지킨다:
- **초안 파일을 편집하지 마라.** 다른 파일도 고치지 마라. 보고 파일 하나만 만든다
- git 명령을 쓰지 마라
- 값이 맞으면 맞다고 센다. 억지로 어긋남을 만들지 마라
- 검사기를 우회하는 표현을 제안하지 마라. 문체를 고치라고도 하지 마라
- 줄 번호를 지어내지 마라. Read 가 붙인 번호를 그대로 쓴다

답장에는 요약 다섯 줄만 적는다.
