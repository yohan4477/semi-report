# OpenAI Jalapeño — 모델 회사가 칩을 만들면 무엇이 달라지나

Hot Chips 발표 12시간도 안 돼 녹음한 회차다. 두 진행자(Austin·Vik)가 슬라이드를 넘겨 가며 읽은 것을 경영 관점으로 다시 정리한다. 칩 내부 구조는 빼고, 이 발표가 돈의 흐름과 경쟁 구도에서 무엇을 건드렸는지만 본다.

---

## 1. 설계 목표가 바뀌었다 — TCO가 아니라 사용자 경험

발표에서 OpenAI 팀(Richard Ho·Ravi·Chris)이 내건 지표는 둘이다.

- 사용자 경험. 단 첫 토큰까지의 시간이 아니라 **마지막 토큰까지의 시간**, 즉 끝에서 끝까지의 지연
- 요청당 에너지

그리고 둘이 서로 물린다고 스스로 밝혔다. 에너지를 더 쓰면 언제든 빨라지므로 단독 수치를 내지 않고 파레토 곡선으로만 보여 주겠다는 것이다.

Austin이 여기서 짚은 것이 이 회차의 경영적 핵심이다. 지금까지 칩 발표는 대부분 **판매사(merchant silicon)**가 했고, 그들의 고객은 AI 랩이나 하이퍼스케일러였다. 그래서 첫마디가 TCO였다. 그런데 Jalapeño를 만든 팀의 고객은 실리콘 구매자가 아니라 **챗봇을 쓰는 최종 사용자**다. 고객이 다르면 설계 판단이 다르다.

```
[판매사 모델]                       [수직 통합 모델 — OpenAI]

  칩 벤더                              모델 랩 = 칩 설계자
    │  판다                              │  스스로 쓴다
    ▼                                    ▼
  하이퍼스케일러 · AI 랩  ← 이 사람이     추론 서비스
    │                       고객이므로      │
    ▼                       "TCO"          ▼
  최종 사용자                            최종 사용자  ← 이 사람이 고객이므로
                                                       "마지막 토큰까지의 시간"
```

Vik은 여기에 Nvidia 젠슨 황이 전에 한 말을 겹쳤다. 칩을 **싸게 만들려고** 아키텍처를 고르면 나쁜 판단이라는 것. 지금 아껴야 할 돈은 제조비가 아니라 운영비, 곧 줄당 토큰(tokens per joule)이다. 에너지를 넣어 토큰을 뽑는 장사이므로 그게 진짜 총소유비용이라는 논리다. 다만 Vik은 개념 자체는 새롭지 않다고 선을 그었다 — 상호작용성 곡선의 세로축에 이미 늘 있던 지표다.

## 2. 9개월이라는 숫자가 진짜 뉴스다

첫 RTL부터 테이프아웃까지 약 9개월. 칩을 해 본 사람이면 말도 안 되게 짧다고 느낄 기간이다. 통상 최소 2~3년이고 손으로 하는 일이 많았다. 초기 RTL은 GPT-3급 모델로 만들었다고 발표에서 언급됐고, 개발이 진행되면서 더 좋은 모델로 갈아탔다.

두 진행자의 해석은 "AI 도구 + 맞는 사람"의 조합이다. Richard가 말한 세 번째 요인은 **백지에서 시작한 것** — 레거시 소프트웨어를 어떻게 맞출지 고민할 필요가 없었다.

```
표준 칩 개발                     Jalapeño
─────────────────────────────    ─────────────────────────────
RTL ──────────────────► 테이프아웃   RTL ───► 테이프아웃
    2~3년, 수작업 다수                 약 9개월
                                       AI 도구 + TPU 출신 팀 + 백지 설계

같은 팀 구성인데 도구만 없던 경우
  d-Matrix, Reiner Pope 등 구글 출신 창업 — 사람과 노하우는 있었으나
  AI 도구는 처음부터 손에 있지 않았다
```

Vik이 이걸 경고로 받은 대목이 중요하다. 1년 안에 Blackwell보다 나은 칩이 나온다면, **2년을 주면 어디까지 가나**. 그리고 그 답이 곧 돈이 어디로 흘러야 하는지를 정한다 — 누구에게 투자해야 하나, 누가 할 능력이 있나. 추론 가속기를 지금 만들고 있는 회사들에게는 기상나팔이다.

다만 그가 붙인 단서도 그대로 적어 둔다. GPT-3급 모델은 어느 회사나 이미 갖고 있다. 그러니 전부가 AI 덕이라고 말하지는 않겠다는 것이다.

EDA 쪽 함의는 갈린다. Austin은 OpenAI가 RTL 작성을 도운 방식이 Cadence·Synopsys가 하는 일과 같은 층위인지 다른 층위인지가 아직 정리되지 않았다고 봤다. Vik은 최소한 "AI를 얹은 EDA가 실제로 먹힌다"는 공개 증거가 하나 생겼다고 봤다. 진입 장벽이 낮아지면 EDA는 오히려 더 팔린다는 것이 이 회차의 결론이다.

## 3. 팔 것인가 — 이 회차에서 두 진행자가 갈린 유일한 지점

Vik이 던진 질문: 구글 TPU도 처음엔 자기들만 썼다. OpenAI도 팔게 될까. 어떤 모델이든 돌아간다는 걸 굳이 보여 준 이유가 뭔가.

### Austin — 팔 길이 있다

수직 통합의 이점(Anthropic·구글 상대 경쟁력, 마진, 속도, 원가 통제, 사용자 경험)은 안 팔아야 지킬 수 있다. 그런데 재무 쪽에 앉으면 다르게 보인다. 짓고 돌리는 비용이 크니 남에게 빌려주거나 팔아 원가를 나누고 싶어진다.

그가 든 비유는 파운드리와 IDM이다. 인텔은 오랫동안 자사 제품팀만 새 공정에 태우려 했다 — 왜 AMD에게 나눠 주나. 그런데 팹 비용이 계속 배로 뛰면 결국 나눠 져야 한다. Jalapeño도 작은 팀이 빨리 만들긴 했지만 테이프아웃과 양산 램프에 1억 달러 수준은 들었을 것이다.

그래서 그가 그린 절충안은 **경쟁자를 피해 가는 판로**다.

```
경쟁 관계 세기별 판로 후보

Anthropic 같은 직접 경쟁 랩 ──── 안 판다
        │
엔터프라이즈(온프레미스·저가 수요) ─── 판다? 또는 빌려준다
        │
네오클라우드 경유 ────────── 네오클라우드가 엔터프라이즈에 빌려준다
        │
"싼 버전 OpenAI 추론 서비스" ── 베어메탈이 아니라 서비스로 판다
        │                       중간 마진이 빠지므로 값이 내려간다
        └── 참고 선례: AWS Trainium
            "우리 XPU에서 돌리니 30% 싸게 드립니다"
```

핵심은 형태다. 칩을 넘기지 않고 **그 칩 위의 추론을 싸게 파는** 길이면 경쟁 우위를 덜 잃는다.

### Vik — 오히려 더 좁혀야 한다

반대 논지다. OpenAI의 고유한 강점은 **자기 모델에만 맞춘 칩**을 만들 수 있다는 것이다. 극단적 코디자인으로 밀면 SRAM 계열(Cerebras급) 성능까지 갈 여지가 있다고 봤다.

그 근거가 데이터다. OpenAI와 Anthropic은 자기 토큰이 실제로 어떻게 쓰이는지, 어떤 워크로드가 도는지를 안다. **Nvidia에게는 없는 정보**다. 토큰을 파는 회사가 아니기 때문이다. 그 정보를 우위로 쓰지 않을 이유가 없다는 것이다.

```
가진 정보                    쓸 수 있는 수

Nvidia   칩 사양 · 벤치마크   범용 최적화
         (토큰 사용 통계 없음)

OpenAI   칩 + 모델 + 실제
         워크로드 분포        모델에 딱 맞춘 코디자인
         + 다음 모델 로드맵    → Cerebras급까지 노려볼 여지
```

### 그리고 Vik이 스스로 뒤집은 부분

범용성이 남는 이유가 하나 있다고 그가 인정했다. Kimi를 굳이 돌릴 필요는 없지만, **범용이어야 자기들의 다음 모델을 이 칩 위에서 키울 수 있다**. 알고리즘이나 하네스 혁신이 나중에 어떻게 오든 하드웨어가 먼저 죽지 않는다.

## 4. 후회 계수 — 무엇을 잘라낼지가 가장 어려운 결정이었다

Ravi가 설계 시점의 비용을 둘로 갈랐다.

| 비용 | 무엇인가 | 크기 |
| --- | --- | --- |
| 한계비용 | 기능 하나 더 넣으면 트랜지스터·플로어플랜이 얼마나 드나 | 작다 |
| 기회비용 | 그 기능이 없어서 못 받는 수요 | 대체로 훨씬 크다 |

기회비용이 한계비용보다 크므로 "안 넣으면 후회할 것"이 판단 기준이 된다 — 발표에서 나온 표현이 후회 계수(regret factor)다. 그런데 넣고 싶은 것을 다 넣으면 칩에 안 들어간다. 그래서 청중이 "가장 어려웠던 결정이 무엇이었나"라고 물었을 때 답이 **무엇을 잘라낼지 정하는 일**이었다.

경영적으로 이게 로드맵을 만든다. 못 넣은 것이 Gen 2로 밀린다.

```
기능 목록(다 넣고 싶다)
      │
      ├─ 후회 계수 높다 ──► Gen 1 = Jalapeño  (손에 들고 나왔다)
      │
      └─ 이번엔 못 넣는다 ──► Gen 2  (이미 테이프아웃 임박)
                              │
                              └──► Gen 3  (검토 중)
```

Gen 2가 이미 테이프아웃에 다가섰다는 것은 1세대를 파는 회사가 아니라 **세대를 돌리는 회사**라는 신호다. Austin이 이 대목에서 짚었듯, 보통 첫 칩은 버리는 칩에 가깝고 경쟁은 2·3·4세대에서 한다. 그런데 이들은 1세대부터 붙었다.

## 5. 벤치마크 — 어디까지 믿을 것인가

OpenAI는 SemiAnalysis의 Inference X를 기준으로 삼았고, 발표에서 공개적으로 공정한 전력 정규화 비교라고 인정했다. 고른 이유가 둘이다.

- 자기에게 맞는 모델 하나를 고르는 대신 **오픈소스 모델 여럿**(작은 것·중간·큰 것)으로 잰다
- 시스템 전체의 끝에서 끝까지 경험을 잰다 — 하드웨어든 소프트웨어든 네트워킹이든 튜닝은 알아서 하라는 것

결과는 두 갈래로 읽힌다.

```
[중간 모델 — DeepSeek R1 671B]
  같은 상호작용성에서 처리량이 GPU보다 높고, 상호작용성 자체도 더 멀리 간다
  → 새 파레토 경계

[작은 모델 — GPT-OSS 120B]
  사용자당 초당 1,000 토큰을 넘긴다 = 지금까지 SRAM(Groq·Cerebras)의 영역
  → GPU 진영은 프리필/디코드를 쪼개(Dynamo) 디코드를 SRAM 칩에 넘기는 방식으로 대응해 왔다
```

다만 진행자들이 스스로 깎은 부분을 빼놓으면 안 된다.

| 유보 사항 | 내용 |
| --- | --- |
| 문맥 길이 | 입력 8K·출력 1K로 쟀다. 백만 토큰 입력에서 어떤지는 안 나왔다 |
| 에이전트 워크로드 | 아직 안 돌렸다. AgentX 벤치마크는 나중 숙제 |
| 메모리 세대 | Jalapeño는 HBM4, 비교 대상 Blackwell·MI355는 HBM3E로 알려져 있다 |
| 공정한 상대 | 그래서 진짜 비교는 Vera Rubin 대 Jalapeño, Helios 대 Jalapeño다 |

Vik의 표현대로 이게 체리픽인지 아닌지는 판별이 어렵다. 쉬운 케이스라고 의심하는 순간 "그럼 어려운 케이스 숫자는 뭐냐"가 되는데 그 숫자가 없기 때문이다. 그럼에도 그가 남긴 판정은 명확하다. HBM4를 감안하면 Blackwell급이 아니라 **Rubin급 칩**이고, 맞는 사람과 맞는 도구가 있으면 1년에 Rubin급을 만들 수 있다는 것이 결론이다.

가장 딱딱한 숫자는 전력이다.

```
칩당 TDP
  Jalapeño   700 W
  GB200      1,200 W 수준(1,000 W 이상)
```

Vik이 Jalapeño의 진짜 강점으로 꼽은 것이 와트당 토큰 처리량이다. Inference X가 전력 정규화라는 점이 여기서 값을 한다 — 전기를 더 먹여 숫자를 올리는 길을 막아 두었기 때문이다.

## 6. 랙 경제학 — 한 칩이 둘을 하면 무엇이 절약되나

같은 성능에 도달하는 다른 길이 없는 것은 아니다. Vik이 분명히 했다. Rubin 시스템에 Groq LPU를 붙이면 그 파레토 곡선은 나온다. 문제는 **몇 랙이 드느냐**다.

```
같은 곡선에 도달하는 두 가지 구성

(A) NVL72 랙 1대 + Groq LPU 랙 아홉 대쯤
     │
     └─ 물어야 할 것: 그만한 비용과 전력을 쓸 값어치가 있나

(B) Jalapeño 랙 한두 대
```

여기에 붙는 것이 이 회차에서 가장 많이 인용될 문장, "다크 실리콘이 노는 가속기보다 싸다"다.

논지는 이렇다. 워크로드마다 프리필 대 드래프팅 대 검증의 비율이 계속 바뀐다. GPU 진영의 해법은 어떤 GPU는 프리필 전담, 어떤 GPU는 디코드 전담으로 나누는 것이다. 그러면 한쪽에 일이 몰릴 때 **반대쪽 랙이 통째로 논다**. OpenAI의 답은 균형 잡힌 칩 하나에 연산·메모리 대역폭·IO를 다 넣고, 안 쓰는 구획은 전원을 끄는 것이다.

```
[분리형]                          [균형형 — Jalapeño]

프리필 전용 랙  ████ 바쁘다        모든 칩이 같은 구성
디코드 전용 랙  ░░░░ 논다          쓰는 구획만 켠다
                                   안 쓰는 구획 = 다크 실리콘

노는 것은 "산 자산 전체"           노는 것은 "칩 안 일부 면적"
```

여기서 자산 수명이라는 경영 논점이 나온다. Rubin에 붙인 Groq LPU는 특정 형식의 디코드에 맞춰져 있다. 그 형식이 바뀌면 효율이 떨어지거나, 아예 쓸 수 있는 워크로드가 좁아진다 — 감가상각을 걸어 둔 실리콘의 **수명이 짧아진다**. Jalapeño는 반대로 Gen 2가 나온 뒤에도 여러 워크로드를 계속 받아 수명이 길 것이라는 주장이다.

같은 논리를 AI ASIC 스타트업들도 펴 왔다는 점은 진행자가 직접 밝혔다. 새로운 주장이 아니라, **이번엔 실물이 붙었다는 것**이 다르다.

## 7. 이 칩이 늘려 주는 매출은 누구 것인가

발표 슬라이드 하단에 Broadcom과 Celestica가 파트너로 명시됐다. 회차에서 확인된 것과 추정인 것을 갈라 둔다.

| 자리 | 회사·사양 | 성격 |
| --- | --- | --- |
| 스케일업 네트워킹 | Broadcom, Tomahawk 6 스위치 | 발표에서 파트너로 호명 |
| 시스템 조립 | Celestica | 발표에서 파트너로 호명. 시스템 레벨 설계 담당이라는 것은 SemiAnalysis 추정 |
| 프로토콜 | ESUN. Broadcom이 앞장선 스케일업 규격, UALink와 다른 것 | 회차 설명 |
| CPU | x86, Turin급으로 추정 | 사람들의 추정. Venice나 인텔 대안도 가능하다는 것이 진행자 견해 |
| 파운드리 | TSMC N3 (N3P/N3E) | 회차 설명 |
| 메모리 | 삼성 HBM4, 핀당 속도가 다소 나을 것 | 진행자가 "전적으로 추정"이라고 못박음 |

경영적 물음은 Austin이 그대로 던졌다. **컴퓨트 최대 소비자 둘 중 하나**가 자기 칩에 만족해서 자기 기가와트를 점점 자기 칩에 태우면, 그 돈은 어느 공급사로 흐르나.

```
OpenAI의 전력 예산이 자체 칩으로 옮겨 갈 때

  GPU 벤더로 가던 몫  ──┬──► Broadcom (스위치 · ESUN)
                        ├──► Celestica (시스템 조립)
                        ├──► TSMC (N3)
                        ├──► 삼성 (HBM4, 추정)
                        └──► x86 CPU 공급사
```

메모리 회사에는 방향이 다른 신호가 하나 더 있다. OpenAI가 발표에서 "우리는 HBM의 능력을 다 쓰고 있지도 않다"고 말했기 때문이다. Vik이 계산을 붙였다 — 랙에 들어가는 128칩의 HBM4 대역폭을 다 합치면 초당 페타바이트급이고, FP4로 1조 파라미터 모델이면 데이터가 0.5테라바이트 정도이니 산술적으로는 초당 2,000 토큰이 나와야 한다. 그런데 안 나온다.

```
HBM 로드맵의 전제               발표가 던진 반문

핀당 10 Gb/s → 16 Gb/s          지금도 다 못 쓰는데
HBM5는 23~24 Gb/s 전망           매년 더 빠르게 만드는 게 맞나
    │                                │
    └─ 매년 세대 교체 = 매출         └─ 있는 것을 다 쓰는 쪽으로
                                        속도를 늦춰야 하는 것 아닌가
```

이건 메모리 업체의 세대 교체 주기 자체를 건드리는 질문이다. Austin이 그대로 정리했다 — 지금 답은 "더 빠르게, 더 빠르게"뿐인데, 가진 것을 먼저 쓰는 쪽을 봐야 하는 것 아니냐는 것이다.

## 8. 경쟁 구도가 받는 압력

```
                        Jalapeño가 보여 준 것
                                │
      ┌─────────────────┬───────┴───────┬──────────────────┐
      ▼                 ▼               ▼                  ▼
   Nvidia · AMD      구글 TPU      SRAM 계열          AI ASIC 스타트업
   범용 GPU                        Groq · Cerebras

 "어떤 모델이든    "TPU는 GPU보다  "1,000토큰/초는   "한 칩으로 둘 다"는
  돌아간다"가       특화돼 있지만    우리 영역"이       원래 그들 주장인데
  더는 유일한       그렇게 좁지는    었는데 범용        모델 랩이 먼저
  차별점이 아니다   않다"는 자리에   추론칩이 들어옴    실물로 들고 나왔다
                    OpenAI도 섬
```

Nvidia가 되받을 논지도 회차에 그대로 있다. **양산해 봐라, 물량으로 출하해 봐라, 대규모에서 얼마나 안정적이냐**. 생산 경험과 가동 시간을 쌓아 온 선두는 당분간 괜찮다는 것이 Austin의 판단이다.

그가 덧붙인 사고 실험은 흥미롭다. Nvidia가 이걸 보고 소규모 별동대를 떼어 **CUDA와 레거시를 잠시 잊고 백지에서 자체 XPU를 1년 안에 세워 보면** 어떤 설계 판단이 나올까. 이건 이 회차에서 나온 가정이지 관측이 아니다.

남은 빈칸은 Anthropic이다. Vik이 물었다 — AMD의 길은 무엇이고, Anthropic의 칩은 어디 있나. 팀이 있다는 것까지만 회차에서 확인된다.
