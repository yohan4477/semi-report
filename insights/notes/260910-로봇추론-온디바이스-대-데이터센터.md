## 이 문서가 주장하는 것

로봇의 지능을 어디에 둘지는 하드웨어가 모델을 결정하는 로봇 특유의 제약(시간·비용) 때문에 LLM과 반대 순서로 정해진다고 본다. 계획층(느리고 무거운 인지)과 행동층(빠르고 가벼운 제어)이 갈리는 계층형 모델에서, 계획층은 무선 지연을 흡수할 수 있어 데이터센터로 옮길 자연스러운 후보가 되고 행동층만 로봇에 남는다고 주장한다. 연산량·전력·공급망(웨이퍼·D램) 세 축 모두에서 로봇 탑재 칩보다 데이터센터 GPU 공유가 유리하다는 근거를 댄 뒤, 로봇 56대 규모 TCO 계산(B300 서버 대 토르 56개)으로 가동률을 반영하면 오프로드가 이긴다고 결론짓는다. 다만 통신망이 아예 존재할 수 없는 환경(동굴·재난 현장)과 안전 대체 루프가 반드시 필요하다는 한계도 명시한다.

## 수치

- 프런티어 로봇 모델 파라미터 수 — Physical Intelligence π0.7 50억 개, 엔비디아 DreamZero 140억 개 (프런티어 LLM의 수조 개와 대비) (L72)
- DreamZero(140억 파라미터, 영상 확산 방식 세계 행동 모델)를 약 7Hz로 실시간 구동하려면 로봇 밖 GB200 두 대 필요 (L74, L175)
- 엔비디아 젯슨 토르(로봇 탑재 칩)의 연산량은 데이터센터 GPU 대비 B200의 약 10분의 1, B300의 약 14분의 1 — GB200 두 대분 연산량은 토르 한 대의 약 20배 (L175)
- 데이터센터 GPU 한 대(블랙웰)는 1.2~1.4kW를 쓰고 물냉각 필요 — 휴머노이드 로봇 전체는 배터리 약 2kWh, 평상시 몇백W·최대 1~2kW (L234)
- 로봇 탑재 두뇌 젯슨 토르는 40~130W, 오프로딩용 인지 연산+무선 통신 보드는 20~30W (L235, L236)
- 매출총이익률 — 블랙웰 데이터센터 GPU 70%대 중후반 대 젯슨 모듈 60%대 중반 (엔비디아 기준) (L257)
- 2030년 젯슨급 칩 100만 개(개당 약 400㎟) 생산 시 연간 웨이퍼 소비량 약 1만 장 (L259)
- D램 탑재량 세대별 증가 — 젯슨 세비어 32GB → AGX 오린 64GB → 젯슨 토르(현재) 128GB LPDDR5X (L292)
- 로봇 56대 기준 가동률 반영 전 TCO — 오프로드(B300 NVL8 1대+로봇당 무선 보드): 자본지출 약 54만 2천 달러·시간당 TCO $18.32. 온로봇(토르 56개, 대당 3,500달러): 자본지출 약 23만 달러·시간당 TCO $6.58 (L318)
- 가동률 반영 후 PFLOP당 TCO — 가정용 로봇 하루 1~2시간(4~8%), Figure BMW 공장 배치 가동률 40%, 공유 GPU 서버 가동률 약 90% 조건에서 오프로드 $0.17/hr 대 온로봇 $0.28/hr, 로봇 4대당 GPU 1대 이상부터 오프로드 유리 (L319)
- 통신 왕복시간 10ms(로봇 근처 온프레미스 GPU 가정) 조건에서 B300 한 대가 로봇 최대 7대 처리 시 p99 지연시간 1.16초(예산 1.6초 이내), 놓친 동작 묶음 0건 (L317)

## 저자가 추정이라고 밝힌 것

- 로봇에서도 스케일링 법칙이 LLM만큼 통할지는 아직 열린 물음이라고 명시한다 — 초기 결과는 조짐만 보일 뿐 검증되지 않았다 (L73)
- 웨이퍼 기준 온로봇 대 오프로드 손익분기점은 로봇 1대당 GPU 7대, D램 기준으로는 로봇 1대당 GPU 5대로 저자들이 계산한 교차점이며 실측치가 아니다 (L286, L305)
