## 이 문서가 주장하는 것

로봇의 지능을 어디에 둘지는 하드웨어가 모델을 결정하는 로봇 특유의 제약(시간·비용) 때문에 LLM과 반대 순서로 정해진다고 본다. 계획층(느리고 무거운 인지)과 행동층(빠르고 가벼운 제어)이 갈리는 계층형 모델에서, 계획층은 무선 지연을 흡수할 수 있어 데이터센터로 옮길 자연스러운 후보가 되고 행동층만 로봇에 남는다고 주장한다. 연산량·전력·공급망(웨이퍼·D램) 세 축 모두 로봇 탑재 칩보다 데이터센터 GPU 공유가 유리하다는 근거를 댄 뒤, 총소유비용을 계산해 가동률을 반영하면 오프로드가 이긴다고 결론짓는다. 다만 통신망이 존재할 수 없는 환경(동굴·재난 현장)과 안전 대체 루프의 필요성은 한계로 명시한다.

## 수치

- 프런티어 로봇 모델 파라미터 수 — π0.7 50억 개, DreamZero 140억 개(프런티어 LLM의 수조 개와 대비) (260910] L72)
- 젯슨 토르(로봇 탑재 칩) 연산량은 B200의 약 10분의 1, B300의 약 14분의 1 — DreamZero(140억)를 7Hz로 돌리는 GB200 두 대분은 토르 한 대의 약 20배 (260910] L175)
- 블랙웰 GPU 한 대 1.2~1.4kW·물냉각 필요 — 휴머노이드 로봇 전체는 배터리 약 2kWh, 최대 1~2kW (260910] L234)
- 로봇 탑재 두뇌 젯슨 토르는 40~130W, 오프로딩용 인지 연산+무선 통신 보드는 20~30W (260910] L235, L236)
- 2030년 젯슨급 칩 100만 개(개당 약 400㎟) 생산 시 연간 웨이퍼 소비량 약 1만 장 (260910] L259)
- 로봇 56대 기준 가동률 반영 전 TCO — 오프로드(B300 NVL8 1대+무선 보드) 시간당 $18.32, 온로봇(토르 56개, 대당 3,500달러) 시간당 $6.58 (260910] L318)
- 가동률 반영 후 PFLOP당 TCO — 가정용 로봇 가동률 4~8%, Figure BMW 공장 40%, 공유 GPU 서버 약 90% 조건에서 오프로드 $0.17/hr 대 온로봇 $0.28/hr, GPU 1대당 로봇 4대 이상부터 오프로드 유리 (260910] L319)
- 통신 왕복시간 10ms(온프레미스 GPU 가정) 조건에서 B300 한 대가 로봇 최대 7대 처리 시 p99 지연시간 1.16초(예산 1.6초 이내) (260910] L317)

## 저자가 추정이라고 밝힌 것

- 로봇에서도 스케일링 법칙이 LLM만큼 통할지는 아직 답이 안 났다고 명시한다(초기 결과는 조짐만 보일 뿐) (260910] L73)
- 웨이퍼 기준 온로봇 대 오프로드 교차점은 GPU 1대당 로봇 7대로, 저자들이 계산한 교차점이며 실측치가 아니다 (260910] L286)
