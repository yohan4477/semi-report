## 이 문서가 주장하는 것

회계사 필명 엘곰은 고려아연을 DCF로 계산해 부록 상세표 기준 주당가치 1,305,033원을 낸다 ([260310] DCF 적정주가 L121). 평가기준일 부근 주가(약 1,617,000원)는 이 값보다 23.9% 높다 ([260310] DCF 적정주가 L131). 필자는 이를 "전통 제련기업의 정상화된 Core DCF만으로는 다소 비싸다"면서도 은·희소금속·미국 제련소라는 아직 실현되지 않은 전략옵션 가치가 가격에 이미 섞여 있다고 해석한다 ([260310] DCF 적정주가 L96). 다만 본문 요약표의 「기준」 시나리오(WACC 7.0%, 같은 Core 가정)는 주당 약 1,360,000원으로 나온다 ([260310] DCF 적정주가 L74). 같은 조합을 더 자세히 푼 부록 상세표의 1,305,033원과는 55,000원가량 차이가 난다. 원문은 이 차이를 스스로 설명하지 않는다 ([260310] DCF 적정주가 L121).

## 수치

- 고려아연 DCF 부록 상세표 주당가치는 1,305,033원이다 ([260310] DCF 적정주가 L129, L130)
- 현재 주가(약 1,617,000원) 대비 차이는 약 +23.9%다 ([260310] DCF 적정주가 L131)
- 본문 요약표 보수적 시나리오(WACC 7.5%) Equity Value 25.4조원·주당 약 1,216,000원 ([260310] DCF 적정주가 L73)
- 본문 요약표 기준 시나리오(WACC 7.0%) Equity Value 28.4조원·주당 약 1,360,000원 ([260310] DCF 적정주가 L74)
- 본문 요약표 낙관적 시나리오(WACC 6.5%) Equity Value 30.9조원·주당 약 1,480,000원 ([260310] DCF 적정주가 L75)
- 시가총액 33.7조원은 본문 기준 DCF(28.4조원) 대비 약 18.7% 높고, 낙관 시나리오(30.9조원) 대비로도 약 9.1% 높다 ([260310] DCF 적정주가 L77)
- 부록 상세표: 5개년 FCFF 현재가치 합계 4,725.5십억원 + Terminal Value 현재가치 23,824.4십억원 = Enterprise Value 28,549.9십억원 ([260310] DCF 적정주가 L116-L118)
- Enterprise Value에서 순차입금 1,310.0십억원을 차감한 Equity Value는 27,239.9십억원이다 ([260310] DCF 적정주가 L119-L120)
- 2026E~2030E 매출액은 18,239.1 → 22,801.1십억원이다(성장률 10.0%→4.0%) ([260310] DCF 적정주가 L104, L105)
- 같은 기간 EBIT margin은 8.2%→8.8%로 오르고 FCFF는 1,061.3 → 1,441.4십억원으로 늘어난다 ([260310] DCF 적정주가 L106, L112)
- 민감도 표(WACC×영구성장률 9칸)에서 현재 주가를 넘는 칸은 WACC 6.5%·영구성장률 3.0%(1,670,329원) 하나뿐이다 ([260310] DCF 적정주가 L138, L142)
- 2025년 연결 매출 16.58조원, 영업이익 1.232조원(영업이익률 7.4%)이다 ([260310] DCF 적정주가 L41)
- 같은 해 당기순이익은 0.775조원, 세전이익은 1,029십억원이다 ([260310] DCF 적정주가 L41)
- 2025년 말 현금및현금성자산 3.451조원, 총차입금 5,799십억원, 순차입금 1.31조원이다 ([260310] DCF 적정주가 L41)
- 2026년 별도 기준 판매계획은 아연 60만톤·연 43만톤·은 1,790톤·금 7,334kg·동 5.36만톤이다. 동 판매량은 2025년 실제 33,001톤에서 확대한 값이다 ([260310] DCF 적정주가 L43)
- 은 가격 $1/oz 상승 시 이익 100~120억원 증가 민감도 ([260310] DCF 적정주가 L43)
- 미국 제련소 프로젝트 — Capex 약 10조원, 운용자금·금융비용 포함 총 11조원, 2029년 상업생산 목표 ([260310] DCF 적정주가 L45)
- 발행주식수 20,872,969주. 2026년 1월 9일 신주 2,209,716주 상장 반영 ([260310] DCF 적정주가 L47)
- Core DCF 가정 중 매출·이익 쪽 — 매출성장률 10%→4%, EBIT margin 8.2%→8.8%, 법인세율 25% ([260310] DCF 적정주가 L58, L59, L60)
- Core DCF 가정 중 현금흐름 쪽 — 감가상각비 매출의 2.26%, Capex 매출의 2.5%, 운전자본 증가 증분매출의 1.0% ([260310] DCF 적정주가 L61, L62, L63)
- Core DCF 가정 중 할인 쪽 — WACC 6.5~7.5%, 영구성장률 2.5% ([260310] DCF 적정주가 L64, L65)
- 연도별 재무 — 2023년 매출 약 11.98조원·영업이익 6,599억원이다 ([260310] DCF 적정주가 L31)
- 2024년 매출 12.1조원·영업이익 7,240억원, 2025년 매출 16.58조원·영업이익 1.232조원이다 ([260310] DCF 적정주가 L32, L33)

## 저자가 추정이라고 밝힌 것

- WACC 6.5~7.5%는 "재무안정성은 좋지만 업황 민감도는 있다"는 판단의 절충치라고 적지만, 베타·무위험이자율·시장위험프리미엄 같은 구성요소 계산 과정은 원문에 없다 ([260310] DCF 적정주가 L164, L168)
- EBIT margin을 2025년 실제 7.4%에서 8.2~8.8%로만 소폭 올린 이유는 2025년 분기별 영업이익률(1분기 11.4%~4분기 13.2%)의 고점을 그대로 장기 마진으로 쓰지 않았기 때문이라고 밝힌다 ([260310] DCF 적정주가 L164)
- Capex를 감가상각비 비율(2.26%)보다 약간 높은 2.5%로 둔 것은 "설비 유지에는 충분하되 미국 제련소 같은 초대형 신사업 투자는 전부 넣지 않은" 구조라고 설명한다 ([260310] DCF 적정주가 L164)
- 미국 제련소(Capex 약 10조원, 총 11조원)는 본체 DCF가 아니라 별도 옵션가치로 다뤘다고 밝히지만, 그 옵션가치를 얼마로 보는지 숫자는 제시하지 않는다 ([260310] DCF 적정주가 L53, L173)
- 현재 주가를 정당화하려면 WACC 6%대 중반 이하, EBIT margin 9% 내외로 구조적 상향, 미국 제련소의 빠르고 높은 ROIC 실현, 은·동·희소금속 가격 강세 장기화 중 여럿이 동시에 필요하다고 정리한다 ([260310] DCF 적정주가 L89-L94)
- 2024년 영업이익이 표에서는 7,240억원, 본문 서술에서는 7,235억원으로 갈리는데 어느 쪽이 맞는지는 밝히지 않는다 ([260310] DCF 적정주가 L169)
- 현재 주가도 본문에서는 1,615,000원이다. 부록에서는 1,617,000원으로 다르게 적혀 있다 ([260310] DCF 적정주가 L171)
- 본문 요약표의 「기준」 시나리오는 주당 약 1,360,000원이다. 부록 상세표의 「기준」 계산은 1,305,033원이다. 같은 WACC 7.0%·Core 가정인데 왜 다른 값이 나오는지는 원문이 설명하지 않는다 ([260310] DCF 적정주가 L170)
