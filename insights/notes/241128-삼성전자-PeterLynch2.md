## 이 문서가 주장하는 것

회계사 필명 엘곰이 전편에서 예고한 피터 린치 공정가치 공식을 삼성전자에 실제로 대입한다. 1차 계산(기대 EPS 성장률 18%, 배당수익률 2.5%, PER 18)은 Fair Value 1.13으로 고평가에 가까운 결과를 내지만, PER를 Forward P/E(9.71)로 바꾼 재계산은 2.1로 적정~저평가로 뒤집힌다. 같은 방법론 안에서도 PER 출처 선택에 따라 결론이 반대로 나올 수 있음을 스스로 보여준다.

## 수치

- EPS 2019~2024: 3,166 / 3,841 / 5,777 / 8,057 / 2,131 / 4,978원, CAGR 22.41%(2023년 △73.5%는 1%로 가정해 계산) (공식 그대로면 1.13 고평가 L19-24)
- 최종 채택 EPS 성장률 18%: 컨센서스 2025년 영업이익 성장률 20.4%, 2026년 13.8%, 야후파이낸스 단기전망 17.89%를 종합 (공식 그대로면 1.13 고평가 L26)
- 배당수익률 2.5%(연 2.5~2.6% 수준), 2024년 PER 11.31(2023년의 50% 미만)로 2023·2024 중간값 18을 1차 PER로 채택 (공식 그대로면 1.13 고평가 L30, L34)
- 1차 계산: (18%+2.5%)/PER 18 = Fair Value 1.13, 피터 린치 기준(1 이하 고평가·1.5 적정·2 이상 저평가)상 고평가에 가까움 (공식 그대로면 1.13 고평가 L41, L43)
- 재계산: Forward P/E 9.71(야후파이낸스, Trailing PE 11.76보다 낮음)을 대입해 (18%+2.5%)/9.71 = Fair Value 2.1(적정~저평가) — 원문은 이 단계 PER를 "11.3"으로 표기했지만 산식에는 9.71을 대입했다 (공식 그대로면 1.13 고평가 L47, L52)

## 저자가 추정이라고 밝힌 것

- 2023년 마이너스 EPS 성장률(△73.5%)을 "주기적 불황 요인을 배제할 수 없다"는 이유로 1%로 대체 가정했다고 명시한다 (공식 그대로면 1.13 고평가 L17)
- 1차 PER로 2023·2024 중간값(18)을 쓴 것에 "중간값이 맞을까?"라고 스스로 재검토 필요성을 제기한 뒤 Forward P/E로 수정한다 (공식 그대로면 1.13 고평가 L34, L47)
