## 이 문서가 주장하는 것

메타가 남는 컴퓨팅 파워를 외부에 파는 사업을 준비 중이라는 소식에 메타는 뛰고 임대만으로 먹고사는 회사들은 빠졌는데, 이 하락을 수요가 식은 신호로 읽으면 안 된다고 가른다. 파는 쪽이 하나 늘었다는 공급 쪽 사건이라는 것이다. 정확한 문장은 경쟁이 격화됐다가 아니라, 격화될 거란 공포가 임대 하나로 버티는 취약한 회사부터 먼저 때렸다이다. 메타는 광고라는 본진이 있어 컴퓨트 임대를 부업으로 해도 되고 가격 경쟁이 붙어도 버티지만, 코어위브·네비우스는 임대 하나뿐이라 같은 경쟁이 생존 문제다. 공급자가 느는 것은 그 시장이 돈이 된다는 판단이 퍼졌다는 뜻이라 오히려 수요가 튼튼하다는 증거로 봐야 하고, 진짜 거품 신호는 수요가 꺾이는 쪽이라고 정리한다. 값 내리기 싸움이 붙으면 판가름은 원가이고, 칩을 사 오는 쪽보다 직접 만드는 쪽이 더 낮은 값을 부를 수 있다는 데서 구글과 아마존을 가른다.

## 수치

- 소식 당일 메타는 10% 넘게 오르고 코어위브와 네비우스는 각각 10%, 12% 넘게 빠졌다 ([260703] 사과가 안 팔리는 것과 사과 가게가 하나 는 것 L38)
- 메타의 2026년 인프라 지출 계획은 1,250억~1,450억 달러로 2025년 약 720억 달러의 거의 두 배다 ([260703] 사과가 안 팔리는 것과 사과 가게가 하나 는 것 L27)
- 앤트로픽은 스페이스X 데이터센터 용량에 월 12억 5,000만 달러, 구글은 다른 용량 일부에 월 9억 2,000만 달러를 낸다 ([260703] 사과가 안 팔리는 것과 사과 가게가 하나 는 것 L58)
- 구글은 TPU 7세대를 출하 중이고 2026년 한 해에만 430만 개를 찍어낼 계획이다 ([260703] 사과가 안 팔리는 것과 사과 가게가 하나 는 것 L67)
- 구글은 제미나이의 75% 이상을 TPU로 돌리는데 트레이니엄은 자사 클라우드 토큰 처리량의 50% 정도를 맡는다 ([260703] 사과가 안 팔리는 것과 사과 가게가 하나 는 것 L69)
- 앤트로픽이 구글 TPU를 최소 100만 개 규모로 쓰기로 했다 ([260703] 사과가 안 팔리는 것과 사과 가게가 하나 는 것 L72)

## 저자가 추정이라고 밝힌 것

- 메타의 클라우드 사업은 확정 발표가 아니라 보도와 주주총회 발언에 기댄 것이다 ([260703] 사과가 안 팔리는 것과 사과 가게가 하나 는 것 L81)
- 스페이스X·앤트로픽 임대료와 TPU 생산 계획은 알려진 수치이고 회사 공시가 아니다 ([260703] 사과가 안 팔리는 것과 사과 가게가 하나 는 것 L82)
- 공급 경쟁이 수요 신호가 아니라는 구분은 지금 국면의 해석이고, 값 내리기가 길어지면 수익성 문제가 되는 시점은 본문에 없다 ([260703] 사과가 안 팔리는 것과 사과 가게가 하나 는 것 L83)
- 트레이니엄3가 엔비디아 대비 절반 수준이라는 것은 추정으로 나온 가격이다 ([260703] 사과가 안 팔리는 것과 사과 가게가 하나 는 것 L76)

## 이 문서가 반박하거나 뒤집는 것

- 네오클라우드(자기 모델 없이 데이터센터를 지어 컴퓨팅 파워만 빌려주는 회사) 급락을 AI 수요 둔화로 읽는 해석을 반박한다. 컴퓨트를 팔겠다는 메타조차 자기 것이 모자라 코어위브·네비우스에서 빌려 쓰고 있다는 것이 근거다 ([260703] 사과가 안 팔리는 것과 사과 가게가 하나 는 것 L55)
- 되팔기로 공급이 곧 늘어난다는 추론에도 선을 긋는다. 코어위브에서 빌린 용량은 2032년까지 제3자에게 되팔 권리가 없다 ([260703] 사과가 안 팔리는 것과 사과 가게가 하나 는 것 L56)
- 자체 칩 경쟁을 아마존 우위로 보는 시각을 뒤집는다. 트레이니엄은 3세대에 와서야 엔비디아 최신 칩과 겨우 대등해진 후발주자라는 것이다 ([260703] 사과가 안 팔리는 것과 사과 가게가 하나 는 것 L67)
