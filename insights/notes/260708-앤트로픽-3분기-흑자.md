## 이 문서가 주장하는 것

앤트로픽은 2026년 6월 1일 비공개로 IPO를 신청했다. 3분기 GAAP(미국 회계기준) 영업이익이 흑자(10억 달러, 마진 6%)인 반면 OpenAI는 영업이익률 -100%로 적자다. 저자들은 이 재무 격차가 두 회사의 향후 자금조달 우위를 나눈다고 본다 — 매출총이익률이 높을수록 재투자 여력이 커지고 다음 모델 경쟁력으로 이어지는 선순환이 생긴다. 앤트로픽은 API·기업 매출 비중이 75~85%로 압도적으로 높은 반면, OpenAI는 소비자·구독 의존도가 높아 무료 사용자 서빙 원가 부담이 크다. SemiAnalysis 기본 시나리오로는 2027년 말 ARR 3,000억 달러에 20배 배수를 적용하면 기업가치 6조 달러로 세계 최대 기업이 될 수 있다.

## 수치

- 3Q26 앤트로픽 GAAP 영업이익 10억 달러(매출 대비 마진 6%), OpenAI는 영업이익률 -100% (3분기 10억 L47)
- 2030년까지 OpenAI·앤트로픽 합산 컴퓨트 수요는 100GW를 초과할 전망, 현재 확보한 컴퓨트는 약 6GW뿐 (3분기 10억 L99)
- 앤트로픽 매출의 75~85%는 사용량 기반 API 매출, 구독은 15%에 불과 (3분기 10억 L155)
- Claude Code는 전체 GitHub 커밋의 7% 이상을 차지하며 앤트로픽 연환산매출(ARR)을 2025년 말 90억 달러에서 현재 600억 달러 이상으로 견인 (3분기 10억 L154, L224)
- 앤트로픽 매출총이익률은 2024년 -94%에서 현재 60%대 중반까지 상승, MW(메가와트)당 ARR은 1,600만 달러(9개월 전)→6,000만 달러(올해 하반기 전망) — 반면 OpenAI는 무료 사용자 9억 명 이상을 1인당 월 약 0.70달러 원가로 서빙해 매출총이익률을 20~30%포인트 깎아먹음 (3분기 10억 L225, L226)
- 코딩 활용 사례가 전체 랩(모델 개발사) ARR의 65% 이상을 차지, 메타는 앤트로픽 전체 매출의 3~5%에 불과한데도 최대 고객으로 추정 (3분기 10억 L302, L303)
- 앤트로픽의 간접 채널(베드락·파운드리 등) 매출 비중은 1분기 전 5~10%에서 현재 15~20%로 확대, 토큰 유통 시장 규모 280억 달러 중 85%를 3대 클라우드가 점유 (3분기 10억 L340, L342)
- 2027년 매출원가 차감 후 재투자 가능 자본은 앤트로픽 1,600억 달러 vs OpenAI 920억 달러로 추정, 앤트로픽 EBTIT(학습비 차감 전 이익) 마진은 2Q26 기준 36% (3분기 10억 L478, L479)

## 저자가 추정이라고 밝힌 것

- SemiAnalysis 기본 시나리오: 2027년 말 ARR 3,000억 달러(월 순증 약 150억 달러 가정) 기준 20배 배수 적용 시 기업가치 6조 달러라는 추정 (3분기 10억 L529)
