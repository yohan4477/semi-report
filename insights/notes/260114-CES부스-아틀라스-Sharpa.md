## 이 문서가 주장하는 것

sudoremove 진행자 JB·JC가 CES 2026 로봇 부스를 돌아본 소감을 정리한 문서다. 보스턴 다이나믹스 양산형
아틀라스는 손가락을 3자유도에서 4자유도로 바꾸고, 구글 딥마인드의 제미나이 로보틱스와 파트너십을 맺어
인바디먼트 리즈닝·액션 디코더·홀바디 컨트롤 3단 구조로 판단을 나눴다고 전한다. LG는 휴머노이드 클로이
D 자체보다 자체 액추에이터 브랜드 AXIUM 공개를 더 눈여겨봤다고 짚는다. Sharpa는 촉각 기반 카드 딜링
데모로 부스 화제를 모았는데, 영상이 배속 없이 1배속으로 재생되고 있다는 점과 텔레오퍼레이션이 아닌
이미테이션 러닝이라는 점을 확인하며 놀란다. Sharpa는 CraftNet이라는 위계형 VTLA 모델을 공개했고,
System 2(장기 판단)·System 1(접촉 전 연속 동작)·System 0(접촉 후 촉각 기반 정밀 동작)로 나눈 구조라고
설명한다. 손 하나 가격이 5만 달러라는 사실도 함께 나온다. 두 회사 모두 판단(장기 계획)과 반사(접촉·균형
같은 즉각 대응)를 나누는 위계 구조로 로봇을 설계한다는 게 문서의 결론이다.

## 수치

- 아틀라스 손가락이 3자유도에서 4자유도로 바뀌었고, 이번 영상에는 실제 과제 수행 장면 없이 서 있는 모습만 나온다 ([260114] CES 부스에서 L12)
- Sharpa 손 하나 가격은 5만 달러, 양손이면 10만 달러라고 진행자들이 어림잡아 계산한다 ([260114] CES 부스에서 L38)
- CraftNet의 System 2는 약 1Hz로 도는 장기 과제 오케스트레이션을 맡는다 ([260114] CES 부스에서 L35)
- CraftNet은 촉각 이미지 열 장을 프로프라이셉션 인코더와 함께 입력받는다 ([260114] CES 부스에서 L36)

## 저자가 추정이라고 밝힌 것

- Sharpa가 사실상 중국 회사라는 판단은 진행자 개인의 추정이라고 스스로 밝힌다 ([260114] CES 부스에서 L28, L54)
- Sharpa 텔레오퍼레이션 장비가 외골격 기반일 것이라는 판단은 공개 정보 부족에 따른 추정이다 ([260114] CES 부스에서 L37)
- 손 하나 5만 달러짜리 제품의 양산 가능성은 회의적으로 보되, 수요가 늘면 가격이 내려갈 거라는 전망을 덧붙인다 ([260114] CES 부스에서 L53)
- 바람개비 접기 데모의 대상 위치가 무작위였을 것이라는 판단도 추정이라고 밝힌다 ([260114] CES 부스에서 L33)
