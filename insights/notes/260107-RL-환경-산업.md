## 이 문서가 주장하는 것

SemiAnalysis는 OpenAI가 같은 베이스 모델(GPT-4o)로 o1부터 GPT-5까지 18개월간 성능을 끌어올린 원동력이 사전학습이 아니라 강화학습(RL, 모델에게 과제를 실제로 수행시키고 그 결과로 보상을 주는 학습 방식) 확대뿐이었다고 주장한다. RL은 사전학습과 달리 인터넷 전체를 재료로 쓸 수 없고 과제·환경을 하나하나 만들어야 하는 노동집약적 산업이라, RL 환경(모델에게 과제를 주고 그 수행 결과로 보상을 매기는 시뮬레이션 공간)을 파는 스타트업만 35개 이상 등장했다. 랩마다 구매 전략은 다르다 — Anthropic은 10여 개 이상의 업체와 계약해 다양성을 유지하고, OpenAI는 총지출은 더 크지만 거래 업체 수를 줄이며 자체 데이터팀을 키우고, 구글 딥마인드는 이미 보유한 자사 플랫폼과 실사용자 신호를 활용한다. 저자들은 랩마다 서로 다른 환경 조합으로 학습하기 때문에 결과물인 모델도 서로 달라질 수밖에 없다고 결론짓고, 이를 "모델은 다 비슷해진다"는 통념과 정반대라고 짚는다.

## 수치

- GPT-5.2는 GDPval(OpenAI의 실제 업무 능력 평가)에서 전문가 결과물과 71% 동률·선호, 44개 직업·1,000개+ 과제 기준 (RL 환경 L41)
- 스케일 AI는 2024년 매출 14억 달러+로 최대 데이터 계약업체였으나 메타 인수 후 다른 랩들이 계약을 대부분 중단 (RL 환경 L99)
- 웹사이트를 복제한 UI 짐 환경은 사이트당 약 2만 달러, OpenAI는 ChatGPT Agent 학습용으로 수백 개 구매 (RL 환경 L100)
- 깃허브 45만 개 PR 중 엄격한 필터링을 거쳐 최종 2만1,336개 과제만 채택 — 약 4.7% 수율 (RL 환경 L163)
- Surge의 추정 연매출은 10억 달러에 근접 (RL 환경 L213)
- Qwen은 현재 사전학습 연산의 약 5%만 후속학습에 투입 (RL 환경 L215)
- Anthropic은 10여 개 이상의 RL 환경 업체와 계약해 가장 공격적인 구매자로 꼽힘 (RL 환경 L264)
- OpenAI 대비 5분의 1 가격으로 서비스하는 소규모 스타트업들이 마진 적자를 감수하며 점유율을 늘리는 중 (RL 환경 L389)
- 메타는 코드 특화 모델에 1조 토큰을 미드트레이닝(사전학습과 RL 사이 추가 학습 단계)에 투입, OpenAI는 이보다 5~10배 많은 양을 쓰는 것으로 추정 (RL 환경 L445)
- 4개의 o4-미니 하위 에이전트 협업만으로 실제 SG랭 커널에서 평균 1.3배 속도 개선을 달성 (RL 환경 L656)
