## 이 문서가 주장하는 것

DCF 모델의 출발점은 회계상 당기순이익이 아니라 실제 현금 창출력인 FCF라고 주장한다. FCFF는 NOPAT + D&A − CAPEX − △NWC라는 네 조각으로 계산되는데, 각 조각(세율 선택, PPA 상각의 add back 여부, 유지·성장 CAPEX 구분, 운전자본 추정)마다 분석가의 판단이 개입할 지점이 있다고 짚는다. 벤처기업은 자본구조가 자주 바뀌어 FCFE 대신 FCFF + WACC법을 표준으로 쓴다고 설명한다. 가장 강조하는 것은 T=0 시점 FCF를 왜곡 없이 정상화(Normalized)하는 작업이 출발점을 틀리지 않게 만든다는 점이다.

## 수치

- 당기순이익 100억에 매출채권 80억 증가, CAPEX 150억 발생 시 FCF는 100−80−150으로 마이너스 130억이 된다 (DCF 프레임워크 1 L22)
- NOPAT은 EBIT × (1 − 실효법인세율)로 구하며 명목세율은 현재 22%다 (DCF 프레임워크 1 L38, L50)
- CAPEX/매출 평균은 소프트웨어·SaaS 3~8%, 바이오·신약 10~20%, 반도체·장치산업 20~40%, 서비스업 2~5%다 (DCF 프레임워크 1 L79)
- 가상 SaaS기업 A사(매출 500억)는 EBIT 75억(15%)에서 출발해 NOPAT 58.5억(11.7%), D&A 20억(4%), CAPEX 25억(5%), △NWC 15억(3%)을 거쳐 FCFF 38.5억(7.7% 마진)에 도달한다 (DCF 프레임워크 1 L124, L131)
- 매출이 10% 성장하면 다음 연도 FCFF는 500 × 1.1 × 7.7% ≒ 42.4억으로 추정된다 (DCF 프레임워크 1 L133)

## 저자가 추정이라고 밝힌 것

- 가상기업 A사의 FCF 산출 예시 전체가 저자가 만든 가정적 사례이며 실제 기업 데이터가 아니다 (DCF 프레임워크 1 L120)
- Normalized FCF는 최근 3~5년 비율의 평균 또는 중앙값에서 일회성 이상치를 제거해 만든 정상 비율이라고, 즉 실측이 아니라 추정 절차의 산출물임을 명시한다 (DCF 프레임워크 1 L118)

## 이 문서가 반박하거나 뒤집는 것

- "성장률이 높은데 왜 FCF가 낮냐"는 통념을 반박한다 — 고성장 기업은 매출 증가를 받쳐줄 CAPEX·운전자본이 더 필요해 성장률이 높을수록 FCF가 낮아지는 역설적 구조라고 짚는다 (DCF 프레임워크 1 L143)
- PPA 무형자산 상각을 유형자산 감가상각과 같이 무조건 add back하는 관행을 반박한다 — 고객관계·기술 상각은 실제 경제적 가치 소멸을 반영하므로 add back하면 FCF를 과대평가한다 (DCF 프레임워크 1 L65)
