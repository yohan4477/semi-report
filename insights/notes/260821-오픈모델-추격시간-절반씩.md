## 이 문서가 주장하는 것

벤치마크 하나로 오픈-클로즈드 격차의 역사를 재면 안 된다는 것이 이 글의 방법론적 출발점이다. 벤치마크는 그 시대 모델을 가르려고 만들어지고 포화되면 버려지므로, 저자들은 LLM 역사를 초기 스케일링·추론·에이전틱 세 시대로 끊어 시대마다 그 시점 벤치마크로 채점했다. 결과는 세대마다 오픈 모델이 그 시대 첫 클로즈드 모델을 따라잡는 시간이 절반씩 줄어든다는 것이다. 저자들은 여기서 프론티어 랩 비관론으로 가지 않는다 — 프론티어 API 토큰 판매가 증설 컴퓨트의 투자수익률이 가장 높은 용도라 두 랩이 계속 더 높은 값을 부를 수 있고, 컴퓨트 격차가 자릿수만큼 벌어지면 효율성만으로 버티는 데 한계가 온다는 것이다.

## 수치

- 1기 시작점에서 GPT-3.5 Turbo 컴포지트 75.7 대 Llama-2-70B 39.9, 격차 35.8점 (260821] 오픈 L122)
- 2024년 12월 딥시크 V3 94.1점이 마지막 프론티어 GPT-4o 95.5점에 사실상 따라붙었다 — Llama-2-70B 출시로부터 약 13개월 (260821] 오픈 L123)
- 2기 시작 격차는 딥시크 R1 대 o1 12.1점으로 1기 35.8점보다 훨씬 좁았다 (260821] 오픈 L160)
- R1-0528이 2025년 5월 78점으로 초기 격차를 해소, o1-preview 출시로부터 8.5개월 (260821] 오픈 L161)
- 클로드 코드 정식 출시(2025년 5월) 이후 앤트로픽 연간반복매출이 650억 달러 이상 늘었다 (260821] 오픈 L190)
- 프론티어 신모델 출시 간격 평균은 1기 213일, 2기 120일, 3기 51일 (260821] 오픈 L193)
- 3기에서 Kimi K2.6이 4.8개월 만에 56.3점으로 Opus 4.5를, GLM-5.2가 6개월 만에 72.4점으로 GPT-5.2를 넘었다 (260821] 오픈 L193)
- 파이어웍스 한 곳이 하루 40조 토큰을 처리한다 — 3월 말 기준 오픈AI API 처리량의 2배 (260821] 오픈 L46)
- 안전성 지연 반론에 대해: GPT-4는 학습 완료부터 출시까지 218일 걸렸다 (260821] 오픈 L237)
- 앤트로픽과 오픈AI를 합쳐도 2026년 신규 기가와트 증설분의 27%뿐이다(간접 하이퍼스케일러 물량 포함) (260821] 오픈 L313)
- 프론티어 API 토큰 판매는 곧 메가와트당 연 1억 달러, 오픈소스 TaaS·기업 코로케이션·추천시스템·레거시 클라우드는 메가와트당 3천만 달러 미만 (260821] 오픈 L314)

## 저자가 추정이라고 밝힌 것

- 앤트로픽 차세대 모델(코드명 Mythos)이 2월 중순 학습을 마쳤다는 것은 가정이고, 그 가정에서 출시 지연은 114일이다 (260821] 오픈 L238)
- 다음 시대에 클로즈드 격차가 다시 크게 벌어지고 새 벤치마크 세트가 필요해진다는 것은 저자들의 전망이다 (260821] 오픈 L266)
- 그럼에도 오픈소스가 새 시대의 초기 격차를 3개월 이내에 좁힐 것으로 본다고 밝힌다 (260821] 오픈 L269)
