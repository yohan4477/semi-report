## 이 문서가 주장하는 것

「로봇 데이터 없이 학습된 Robot Foundation Model」 편은 스텔스에서 나온 Sunday Robotics의 로봇 '메모'를 계기로 세 회사의 데이터 수집 방식을 가른다. Sunday Robotics와 Generalist AI는 로봇을 원격조작하지 않고, 사람이 UMI 그리퍼 방식 장치(손에 쥐는 카메라 달린 도구)로 동작을 찍은 뒤 역기구학으로 로봇 팔에 옮겨 심는다. 두 회사 모두 이 방식을 로봇 원격조작과 구분한다. 반면 Physical Intelligence는 π*0.6에서도 실제 로봇을 사람이 원격조작하는 방식을 그대로 쓰고, 지도학습 베이스 모델에 강화학습을 얹어 사람 개입 보정을 반영한다. 그래서 제목의 '로봇 데이터 없이'는 앞의 두 회사에만 맞고 Physical Intelligence에는 적용되지 않는다. 진행자들은 이 방식이 원격조작보다 효율적이라 인정하면서도, 사람 손 동작과 로봇 몸체 동작 사이 도메인 갭이 검증되지 않았고 '스케일러블'이라는 표현도 과하다고 지적한다. 데이터 규모는 회사 자체 발표치일 뿐, 성공률 같은 정량 지표는 어느 회사도 공개하지 않았다.

## 수치

- Sunday Robotics가 로봇 '메모' 제작 원가로 2만 달러를 밝혔다 ([251125] 로봇 데이터 없이 L13)
- Generalist AI가 공개한 데이터 규모는 에피소드 1000만 개, 총 270,000시간이다 ([251125] 로봇 데이터 없이 L24)
- 비교로 나온 HuggingFace 갤럭시아 데이터셋은 500시간으로 Generalist AI보다 훨씬 작다 ([251125] 로봇 데이터 없이 L25)
- Sunday Robotics는 16개 노드(각 8-GPU) 구성과 3개월이라는 학습·수집 규모를 언급했다 ([251125] 로봇 데이터 없이 L17)

## 저자가 추정이라고 밝힌 것

- 진행자들은 '메모'의 자유도를 팔 7, 손 4 정도로 읽었지만 화면만 보고 추정한 것이라 확신하지 못했다 ([251125] 로봇 데이터 없이 L12)
- 3개월이 데이터 수집 기간인지 모델 학습 시간인지는 영상에서도 분명히 갈리지 않는다고 밝혔다 ([251125] 로봇 데이터 없이 L17)
- 성공한 궤적만 걸러 썼을 뿐 전수 검증은 아니었을 것이라고 추정했다 ([251125] 로봇 데이터 없이 L46)
- 두 회사의 방식이 닮은 이유를 학계 계보에서 찾는 것은 진행자들의 해석이다 ([251125] 로봇 데이터 없이 L26)
