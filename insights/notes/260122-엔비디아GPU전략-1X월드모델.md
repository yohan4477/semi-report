## 이 문서가 주장하는 것

엔비디아 GEAR팀의 짐 판(Jim Fan)과 스펜서 항(Spencer Huang)은 VLM 기반 VLA가 근본적으로 틀렸을 수 있다며 비디오 모델 기반 로봇 정책을 밀고 있고, 진행자들은 이 주장의 배경에 비디오 모델이 VLM보다 GPU를 훨씬 많이 쓴다는 엔비디아의 판매 유인이 있다고 짚는다. 1X Technologies는 로봇 NEO를 실제로 구동하는 데 Redwood AI World Model(비디오 모델+IDM 구조)을 처음 투입한 영상을 공개했다. 그동안 평가용으로만 쓰던 월드모델을 실행 자체에 쓴 사례로, 사람 1인칭 영상 900시간 중간학습 뒤 로봇 자체 데이터는 70시간만 파인튜닝했는데도 텔레오퍼레이션으로 모으기 어려운 과제까지 수행했다고 주장한다. IDM은 400시간 분량(의미 없는 무작위 동작 포함)으로 학습했다. 가장 큰 약점은 속도로, 5초짜리 비디오 생성에 11초가 걸리고 IDM 추론까지 더하면 12초라 즉각 반응이 필요한 과제는 못 하며 클로즈드 루프가 안 된다. 같은 접근으로 mimic Robotics는 프리트레인된 비디오 모델에 텔레오퍼레이션 데이터로 액션 디코더만 파인튜닝했고, 테슬라 옵티머스 전 리드 밀란 코박도 사람 비디오 학습 단일 신경망 데모를 보인 뒤 보스턴 다이나믹스로 옮겼다. IDM 자체의 모델 구조는 공개되지 않아 진행자들도 모른다고 밝힌다.

## 수치

- 사람 1인칭 영상 900시간으로 중간학습한 뒤 로봇 자체 데이터는 70시간만 파인튜닝했다 ([260122] 엔비디아 GPU L18)
- IDM은 400시간 분량으로 학습했고 의미 없는 무작위 동작 데이터도 섞였다 ([260122] 엔비디아 GPU L19)
- 140억 파라미터 비디오 모델이 5초짜리 비디오를 만드는 데 11초, IDM 추론 1초를 더해 총 12초가 걸린다 ([260122] 엔비디아 GPU L34)
- 비디오모델+리워드모델로 강화학습을 직접 돌리는 네 번째 용도는 너무 어려워 자세히 다루지 않는다 ([260122] 엔비디아 GPU L14)

## 저자가 추정이라고 밝힌 것

- 비디오모델(월드모델) 평가와 실제 로봇 성능 사이에 어느 정도 상관관계가 있다는 정도로만 말하고 정량 수치는 제시하지 않는다 ([260122] 엔비디아 GPU L42)
- 잡는 지점이 사람처럼 나오는 것은 사람 1인칭 영상 학습의 영향일 것이라는 추정이다 ([260122] 엔비디아 GPU L22)
- mimic Robotics의 국적(스위스·ETH 취리히)은 확신하지 못한 채 추정으로 남긴다 ([260122] 엔비디아 GPU L45)
