## 이 문서가 주장하는 것

RLWRLD가 낸 로봇 파운데이션 모델 RLDX-1을 sudoremove 진행자 둘이 "SOTA 오픈웨이트"라는 표현이 실제로 무엇을 가리키는지 갈라 뜯는 영상이다. 공개 범위는 모델 가중치 세 종·인퍼런스와 학습과 LoRA 코드·사전학습 데이터 구성 비율까지로, 로보틱스 파운데이션 모델 중 이례적으로 넓다고 확인한다. 아키텍처는 모션·피직스·메모리 세 모듈로 기존 VLA가 못 보던 신호(속도·방향, 접촉 토크, 과거 프레임)를 더하고, 이 신호들을 MSAT(Multi-Stream Action Transformer)가 모달리티별 스트림으로 나눠 처리한다. 동시에 진행자들은 어블레이션 실험이 거의 없고, 벤치마크 자체가 기존 VLA가 구조적으로 못 푸는 과제 위주로 설계돼 RLDX-1에 유리하다는 점을 짚는다. 동료 심사를 거친 논문이 아니라 회사 테크니컬 리포트이며, 강화학습 단계의 밸류 모델을 구체적으로 어떻게 만들었는지는 이 편에서 상세히 다루지 않는다. 물을 따르는 것처럼 보이는 양팔 데모가 실은 구슬을 쓴 것이라는 점도 진행자가 직접 확인해 짚는다.

## 수치

- 가중치 세 종(PT·MT-ALLEX·MT-DROID)을 허깅페이스에 공개했다 ([260518] RLDX-1이 연 L22)
- 인퍼런스·학습·LoRA 코드까지 셋 다 공개했다 ([260518] RLDX-1이 연 L23)
- 코그니션 토큰 64개가 비전-언어 정보를 압축해 메모리 모듈로 넘긴다 ([260518] RLDX-1이 연 L14)
- 8B(80억) 파라미터라 구성 요소별 어블레이션을 다 돌리기 어렵다고 짚는다 ([260518] RLDX-1이 연 L26)
- 컨베이어벨트를 1배·3배로 학습해 학습하지 않은 중간 속도에서도 성공했다 ([260518] RLDX-1이 연 L10)

## 저자가 추정이라고 밝힌 것

- 아키텍처와 데이터 중 무엇이 성능 개선의 주된 원인인지 "만드신 분도 명확하게 수치로 제시하지 못할 것"이라며 답을 유보한다 ([260518] RLDX-1이 연 L40)
- MSAT의 어텐션 방식(셀프냐 코절이냐)은 논문 텍스트가 아니라 그림 구조로 추정한 것이라고 스스로 밝힌다 ([260518] RLDX-1이 연 L18)
- 일반 목적 리워드 모델을 만드는 일이 어렵다는 점은 짚지만 RLDX-1이 이를 어떻게 풀었는지는 상세히 설명하지 않는다 ([260518] RLDX-1이 연 L41)
