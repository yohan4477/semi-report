## 이 문서가 주장하는 것

VLA가 LLM처럼 규모를 키워 성능을 얻는 길을 그대로 못 밟는 이유를 셋으로 나눈다 — 행동 데이터가 인터넷에 존재하지 않고, 성능 평가에 실물 로봇이 필요해 하드웨어 파손 위험 때문에 자동 벤치마크를 돌릴 수 없으며, 촉각 센싱과 손 하드웨어 제조가 아직 덜 됐다는 것이다. 특히 두 번째가 개발 반복 속도를 직접 깎는 지점이라고 본다. 이를 뚫으려는 수집 경로 다섯을 늘어놓되, 어느 것도 스케일 문제를 푼다고 입증되지 않았다고 결론짓는다.

## 수치

- 테슬라는 옵티머스 학습용 원격 조작자를 시급 48달러에 뽑았다 (Action Data Scaling 문제 L12)
- 조작자 조건은 키 170~180cm, 하루 7시간 이상 보행, 13kg(30파운드) 운반이며, VR 장비를 오래 쓰면 피로와 멀미가 와서 지속 시간이 한계다 (Action Data Scaling 문제 L12)
- 수집 경로는 다섯이다 — 텔레오퍼레이션, UMI(사람이 들고 다니는 집게), 시뮬레이션, 커뮤니티 오픈소스, 월드모델+IDM (Action Data Scaling 문제 L12-L16)
- 엔비디아 Isaac GR00T가 합성 데이터를 만들지만 시뮬레이션과 현실의 차이(sim-to-real gap)를 메우는 것이 관건이다 (Action Data Scaling 문제 L14)
- 1X Technologies는 레이블 없는 영상에서 IDM(역동역학 모델)으로 행동을 역추출해, 인터넷에 쌓인 사람 행동 영상을 데이터원으로 바꾸려 한다 (Action Data Scaling 문제 L16)
- LLM은 데이터원이 인터넷이고 수집 비용이 낮으며 평가가 자동인 반면, VLA는 실물 로봇 동작이라 비용이 높고 평가에 실물이 필요하다 (Action Data Scaling 문제 L28-L30)

## 저자가 추정이라고 밝힌 것

- 다섯 경로 중 어느 것도 스케일 문제를 푼다고 아직 입증되지 않았다 (Action Data Scaling 문제 L17)
