## 이 문서가 주장하는 것

Claude Code(터미널에서 계획을 세우고 직접 실행까지 하는 AI 에이전트)는 2022년 ChatGPT 모먼트에 맞먹는 변곡점이라고 저자는 주장한다. AI의 미래는 토큰을 원가에 파는 것이 아니라 여러 단계를 조율(오케스트레이션)하는 데 있으며, 코딩은 자동화의 첫 교두보일 뿐 정보 노동 전체가 다음 목표다. 앤트로픽은 벤치마크 점수가 아니라 같은 작업을 더 적은 토큰으로 끝내는 토큰 효율성 덕분에 앞서 있고, 이 우위가 마이크로소프트 같은 좌석당 과금 소프트웨어 기업을 직접 위협한다.

## 수치

- GitHub 공개 커밋의 4%를 Claude Code가 작성 중이며, 이 추세라면 2026년 말까지 일일 커밋의 20% 이상을 차지할 전망이다 (Claude Code L38)
- 전 세계 정보 노동자는 10억 명 이상(전체 노동인구 36억 명의 약 1/3)이고, 잠재 시장은 15조 달러 규모 정보 노동 경제 전체다 (Claude Code L174)
- 에이전트가 실패 없이 혼자 처리할 수 있는 작업 시간(과업 지평선)이 METR 측정 기준 4~7개월마다 2배로 늘고, 2024~2025년엔 그 주기가 약 4개월로 가속됐다 (Claude Code L212)
- 앤트로픽은 2026년 1월 12일 데스크톱용 에이전트 Cowork를 출시했는데, 엔지니어 4명이 10일 만에 개발했다 (Claude Code L214)
- Stack Overflow 2025 설문에서 코더의 84%가 AI를 쓰지만 코딩 에이전트 사용은 31%뿐이다 (Claude Code L215)
- 미국 지식노동자 완전부담 비용은 하루 350~500달러인데, 에이전트가 업무 일부만 대신해도 일 6~7달러 수준이면 ROI(투자 대비 수익) 10~30배다 (Claude Code L264)
- 액센츄어는 전문인력 3만 명에게 Claude 교육을 진행하는 역대 최대 규모 배포 계약을 체결했다 (Claude Code L265)
- 앤트로픽의 곧 있을 밸류에이션은 약 3,500억 달러로, 기가와트(GW)급 전력 확보 경쟁에 투입될 자금으로 전망된다 (Claude Code L429)

## 저자가 추정이라고 밝힌 것

- SemiAnalysis Tokenomics 모델은 앤트로픽이 향후 3년간 오픈AI만큼의 전력(연산 인프라)을 확보할 궤도에 있다고 추정한다 (Claude Code L40)
