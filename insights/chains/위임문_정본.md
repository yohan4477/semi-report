# 체인 정본 세우기 위임문

## 하는 일

한 섹션에 배정된 **추출 체인 여러 개를 정본 사슬로 합친다**. 채널이 같은 산업을 여러 회차에
걸쳐 깠기 때문에 사슬이 쪼개져 있다 — 원전은 여섯 편, 제약 유통은 일곱 편이다. 독자가
한 번에 읽을 수 있게 사슬 하나로 세우되, 근거 줄은 하나도 안 버린다.

재료는 `insights/chains/extract/*.json`. 원문은 `content/understanding/채널 씨모어/raw/<슬러그>.md`.
산출은 `insights/chains/canon/<정본슬러그>.json`.

## 어떻게 합치나

1. **같은 사슬인지 먼저 가른다.** 단계 이름이 달라도 물건·돈이 지나가는 자리가 같으면 같은
   사슬이다(「우라늄 채굴」과 「금광 보유국·채굴업체 계약」은 다른 산업이니 다른 사슬,
   「신약 물질 발굴」과 「R&D(후보물질 발굴·최적화)」는 같은 자리다).
2. **가장 자세한 회차를 뼈대로 삼는다.** 마디가 일곱인 회차가 있으면 그것을 기준으로 놓고,
   다른 회차의 마디를 그 자리에 얹는다. 다른 회차에만 있는 마디는 순서대로 끼워 넣는다.
3. **회사는 합집합이다.** 여러 회차가 같은 마디에 다른 회사를 댔으면 다 넣는다. 같은 회사를
   두 회차가 댔으면 하나로 합치고 `refs` 에 둘 다 남긴다.
4. **판단이 갈리면 둘 다 적는다.** 진행자가 나중 회차에서 앞 판단을 뒤집었으면 (예: 제약
   생산 단계를 병목이라 했다가 판단을 유보) `judgment` 에 날짜와 함께 둘 다 적는다.
   최신 것으로 덮지 않는다 — 생각이 바뀐 것 자체가 이 장의 값이다.
5. **하위 사슬은 따로 세운다.** 부모 사슬의 마디 하나를 확대한 것이면 별도 정본 파일로
   만들고 `parent`(부모 정본 슬러그)와 `parent_stage`(부모의 마디 이름)를 적는다.

## 절대 규칙

- **원문에 없는 것은 안 적는다.** 네가 아는 업계 지식으로 마디를 채우거나 회사를 보태지 않는다.
- **모든 근거는 `refs` 로 남긴다.** `[{"src": "<원문 슬러그>", "lines": "L44~L46"}]` 꼴.
  줄 번호는 그 원문 파일을 1부터 센 번호(frontmatter·빈 줄 포함). 떨어진 대목은 쉼표로 잇는다.
  **추출물의 줄 주소를 그대로 옮기면 된다** — 새로 세지 않는다. 다만 옮긴 뒤 표본 세 개는
  `sed -n '44,46p'` 로 확인한다.
- 회사 이름은 추출물의 `name`·`raw_name` 을 그대로 옮긴다. 자막이 뭉갠 표기를 고치지 않는다.
- 마디 `order` 는 1부터 빈틈없이.

## 산출 형식

```json
{
  "canon_slug": "nuclear-fuel",
  "section": "nuclear",
  "chain_name": "우라늄이 연료가 되어 타고 남는 사슬",
  "one_line": "이 사슬에서 무엇이 걸리는지 한 문장. 결론만 — 물음도 배경도 안 쓴다",
  "sources": [{"src": "2025-06-29-nuclear-valuechain", "date": "2025-06-29"},
              {"src": "2025-06-08-centrus", "date": "2025-06-08"}],
  "parent": "", "parent_stage": "",
  "stages": [
    {
      "order": 1,
      "name": "우라늄 채굴",
      "desc": "원문이 이 자리를 설명한 내용. 사실만.",
      "refs": [{"src": "2025-06-29-nuclear-valuechain", "lines": "L44~L46"}],
      "companies": [
        {"name": "카자톰프롬", "raw_name": "", "country": "카자흐스탄",
         "role": "세계 우라늄의 43%를 담당", "numbers": "점유율 43%",
         "refs": [{"src": "2025-06-29-nuclear-valuechain", "lines": "L52~L54"}]}
      ],
      "bottleneck": "high",
      "bottleneck_why": "농축 권한을 가진 나라가 많지 않아 아무나 못 들어온다",
      "bottleneck_refs": [{"src": "2025-06-29-nuclear-valuechain", "lines": "L60~L62"}],
      "judgment": "진행자 판단. 회차마다 갈리면 날짜를 붙여 둘 다. 없으면 빈 문자열"
    }
  ],
  "notes": "사슬 전체에 걸린 진행자 판단·경고. 없으면 빈 문자열"
}
```

- `bottleneck` 은 `high|mid|low|""`. **원문이 진입장벽·독과점·문지기라고 말한 마디만 high.**
- `canon_slug` 는 영문 소문자·하이픈. 파일명과 같아야 한다.
- `one_line` 은 카드 한 줄 코멘트가 된다. **결론만 쓴다** — 「무엇을 볼 것인가」 같은 물음이나
  「이 사슬은 …이다」 같은 정의문은 안 쓴다. 숫자나 이름이 들어가면 좋다.

## 스스로 검사

만든 뒤 반드시:

```
PYTHONIOENCODING=utf-8 python insights/check_chain.py --canon
```

FAIL 0 이어야 끝난 것이다. FAIL 이 나오면 고치고 다시 돌린다.
