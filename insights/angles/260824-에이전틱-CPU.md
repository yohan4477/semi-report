# GPU 옆에 CPU 를 몇 개나 두어야 하나 — Grok bot 과 에이전틱 CPU

원문은 Semi Doped 팟캐스트 전사본이다. 게스트 없이 진행자 둘이 그 주 출시된 xAI의
Grok bot을 계기로 「GPU=천재, CPU=비서」 비유를 세워 대화한다. 값의 대부분은 두 사람의
개인 경험·프레이밍이고, 수요 규모(10억 코어)는 진행자가 스스로 「사고실험」이라고
못박은 임의의 곱셈이다.

## 저자 논지

두 진행자는 에이전트를 돌리는 수요가 **GPU가 아니라 CPU 쪽으로 번지는 경로**를
「천재-비서」 비유로 정리한다. GPU 바로 옆에서 GPU를 먹이는 호스트 노드 CPU와, 코드
컴파일·웹 검색 같은 여분의 작업을 전담할 별도의 「에이전틱 CPU」를 나눠야 한다는
것이다. 다만 이 구분을 뒷받침할 CPU·GPU 통합 오케스트레이션 소프트웨어는 아직 없다고
스스로 인정하고, 수요 규모(10억 코어)는 임의로 잡은 사용자 수·에이전트 수를 곱한
사고실험일 뿐이다.

## 다음 글이 채울 자리

- 10억 코어 수요 — 1천만 명×VM당 100개 에이전트라는 임의 가정을 곱한 값이지 실측치나
  업계 전망치가 아니다(§주의 L73).
- Grok bot의 실제 CPU·리전 등 인프라 사양 — 진행자도 직접 확인이 아니라 사용 경험으로
  추정한 것이다(§주의 L74).
- 에이전틱 CPU와 범용 CPU 사이의 실제 작업 분배 비율 — 앤트로픽·오픈AI에 공유를
  요청한 상태이고 아직 답은 없다(§사실 L48).
