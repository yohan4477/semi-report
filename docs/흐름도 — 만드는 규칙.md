# 흐름도 — 만드는 규칙

돈·물건·의무가 **주체 사이를 오가는 그림**을 그릴 때 따른다. 「누가 누구에게 무엇을 주고, 그 대가로 무엇이 돌아오는가」가 요점인 그림이다. 전제는 `insight-figure` 스킬 넷(없는 값 금지·좌표 계산·판 위 글자 금지·검사기) — 그 위에 얹는다.

본은 Epoch AI의 앤트로픽 파이낸싱 도해 3장이다(컴퓨트/데이터센터 대조, AI XPV Platform 단면, Lake Mariner 단면).

---

## 0. 먼저 — 흐름도를 쓸 자리인가

| 요점 | 형태 | 흐름도 아님 |
|---|---|---|
| **누가 누구에게 무엇을 주나** | 흐름도 | |
| 어디냐 | | 지도 |
| 언제냐·순서 | | 시간축 하나에 상태 둘 |
| 얼마나 크냐 비교 | | 막대(단, 원문에 값이 있을 때만) |
| 조건과 결과가 어긋난다 | | 좌우 대비 |
| 무엇이 무엇에서 갈라져 나왔나 | | 계보 나무 |

**주체가 셋 미만이면 흐름도를 그리지 않는다.** 문장 하나가 더 빠르다. 주체 셋~일곱, 오가는 것 두 종류 이상일 때가 흐름도 자리다. 여덟을 넘으면 그림을 둘로 쪼갠다.

### 흐름도 안에서 어느 판을 쓰나

| 상황 | 판 | 본 |
|---|---|---|
| 서로 다른 두 건이 **같은 구조**임을 보인다 | **두 칸 대조** — 좌우 같은 행, 가운데 역할 라벨 공유 | 1번 그림 |
| 한 건의 **자금 한 바퀴**를 보인다 | **한 줄 세로 스택** — 돈 대는 쪽 위, 갚는 쪽 아래 | 2번 그림 |
| 주체가 여럿이고 **역할군이 갈린다**(대주·개발·고객) | **세 칸 배치** — 칸마다 역할군, 묶이는 회사는 컨테이너로 감싼다 | 3번 그림 |
| 위 셋에 안 맞는다 | 요점이 흐름이 아닐 가능성이 크다. 0절로 돌아간다 | |

두 칸 대조를 쓰려면 **행이 실제로 대응해야 한다.** 왼쪽 3행과 오른쪽 3행이 다른 것이면 대조가 거짓말이 된다. 대응이 안 되면 한 줄 스택 둘로 나눈다.

---

## 1. 제목은 라벨이 아니라 문장이다

```
✕ 앤트로픽 컴퓨트 파이낸싱 구조
✓ 앤트로픽의 리스와 브로드컴의 후순위 보증이 TPU에 345억 달러를 끌어온다
```

제목이 결론을 말한다. 그림은 그 결론을 어떻게 아는지를 보인다. 부제는 한두 줄로 **순서**를 적는다 — 누가 대고, 누가 짓고, 누가 갚는지. 명사 나열이 아니라 동사로.

## 2. 선은 세 종류뿐, 범례는 그림마다 똑같이

| 뜻 | 모양 |
|---|---|
| 돈이 흐른다 | 강조색 실선 + 화살촉 |
| 물건·용역·리스가 간다 | 회색 실선 + 화살촉 |
| **조건부** 지원(부도 뒤에만) | 회색 **점선** + 화살촉 |

세 줄 범례를 그림 판 위쪽에 **매번 같은 문구로** 둔다. 한 장만 볼 사람이 대부분이다.

점선이 핵심이다 — 조건부 의무를 실선으로 그리면 「보증이 있다」로 읽힌다. 실제로는 부도 뒤에만 작동한다. **색이 아니라 대시로 구분한다**(흑백 인쇄·색각 이상에서도 남는다).

## 3. 역할 라벨은 상자 밖 도랑에 둔다

`대는 쪽 / 조달 법인 / 대상 자산 / 갚는 쪽 / 벤더 지원` — 작은 대문자·회색으로 **가운데 도랑(두 칸 대조)이나 상자 위(세 칸 배치)**에 세운다. 상자 안에 넣지 않는다. 역할은 행의 성질이지 그 회사의 이름이 아니다.

두 칸 대조에서 이 도랑이 대조를 성립시킨다. 같은 행 = 같은 역할, 이름만 다르다.

## 4. 강조색 상자는 그림당 한 종류

**이 그림이 무엇을 뜯어보는 것인지**를 칠한다. Epoch은 조달 법인(SPV·프로젝트 회사)만 강조색으로 채웠다. 나머지는 흰 상자 + 옅은 테두리.

강조를 둘 이상 쓰면 어느 쪽이 주인공인지 사라진다. 묶음을 보일 때는 더 옅은 같은 색 **컨테이너**로 감싼다(3번 그림의 「TeraWulf 자회사군」이 Wulf Compute·Akela 둘을 감싼 것).

## 5. 숫자는 그것을 가진 상자 안에 산다

```
✓ 기관투자자 / 345억 달러 확약
✓ 데이터센터 / 378MW, Fluidstack에 리스
✓ 브로드컴 / 300억 달러 후순위 보증, 최대 노출 290억 달러
```

떠다니는 숫자 딱지를 만들지 않는다. 상한이 있으면 둘째 줄에 적는다(「최대 노출 …」). 상자 설명은 **그 주체가 하는 동사**로 쓴다 — 「랙을 사고 보유한다」, 「짓고 소유한다」. 형용사로 쓰지 않는다.

## 6. 선 위 글자는 오가는 것의 이름이다

```
✓ 랙 배치에 맞춰 16회 분할 인출
✓ 이자와 원금
✓ 5년 확약 리스료
✓ 용량이 넘어오는 만큼의 임대료
```

**글자 색은 그 선의 색을 따른다.** 돈 선의 라벨은 강조색, 용역 선의 라벨은 회색. 이걸 어기면 범례가 무너진다.

조건부 선에는 **발동 조건을 문장으로** 붙인다 — 「Fluidstack이 부도나면 구글이 밀린 임대료를 대납하거나, 리스를 승계하거나, 해지금을 내어 채무에 충당할 수 있다」. 조건 없는 점선은 읽는 사람이 실선으로 읽는다.

## 7. 먼 관계는 바깥 레일로 돌린다

「리스료가 선순위 채무를 갚는다」처럼 위아래 멀리 떨어진 두 상자를 잇는 선은 **판 바깥 세로 레일**로 돌리고 글자를 세워 붙인다. 가운데를 가로지르면 다른 선과 엉킨다.

선은 직각으로만 꺾는다. 대각선 금지 — 겹치면 어느 것이 어느 것인지 못 가른다.

## 8. 각주 세 줄로 닫는다

1. **그림이 오해를 부를 자리를 미리 막는다** — 「두 파이낸싱은 법적으로 별개다」, 「Lake Mariner는 데이터센터 쪽의 한 예다」. 나란히 그렸다고 한 묶음이 아니다
2. **추정치는 추정치라고** — 「2026년 7월 기준 가동 42MW, 10월 +168MW 예정」
3. **출처를 이름으로** — 「TeraWulf 공시·투자자 자료」

## 9. 안 하는 것

아이콘·이모지·그림자·그라데이션·3D·곡선 화살표. 상자는 얇은 테두리에 작은 라운드만. 글자 크기는 넷까지(제목·상자 이름·본문·역할 라벨).

## 구현 — 클래스 세 벌

`card_lib.EXTRA_CSS`의 `.flow` 하나로는 세 종류를 못 낸다. 흐름도를 붙일 때 아래 셋을 쓴다(없으면 먼저 추가한다).

```css
.uc-fig .flow-cash{fill:none;stroke:var(--fig-good,#2f8f6b);stroke-width:1.8;marker-end:url(#fig-arrow-a)}
.uc-fig .flow-svc {fill:none;stroke:var(--ink-3);stroke-width:1.6;marker-end:url(#fig-arrow)}
.uc-fig .flow-cond{fill:none;stroke:var(--ink-3);stroke-width:1.4;stroke-dasharray:5 4;marker-end:url(#fig-arrow)}
```

`fig-arrow-a`는 강조색 화살촉이다 — `FIG_DEFS`에 마커를 하나 더 둔다. 미리보기 HTML에서 `FIG_DEFS`를 빠뜨리면 화살촉이 통째로 안 그려진다.

## 마치기 전

- [ ] 제목이 문장인가 (명사 라벨이면 다시)
- [ ] 범례 세 줄이 판 위에 있나
- [ ] 조건부 선이 점선이고 발동 조건이 붙었나
- [ ] 강조색 상자가 한 종류인가
- [ ] 선 위 글자 색이 그 선 색과 같나
- [ ] 두 칸 대조라면 좌우 행이 실제로 대응하나
- [ ] 숫자가 전부 상자 안에 있고 원문에 있나 (`insight-figure` 규칙 1의 대조 스크립트)
- [ ] `check_fig.py` FAIL 0인가
