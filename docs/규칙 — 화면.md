## 1. 화면

```
글 페이지     제목 → 메타(날짜·화자·원문·요약본) → 화자 상자 → 판 제목 → 여는 문단 → 차례 → 절
화자 상자 (S1) 말한 사람만. 진행 / 게스트 / 발표 로 가르고, 원문에 없는 소속·직함은 안 적는다.
              진행자가 인용한 기사·회사는 화자가 아니다. frontmatter people 에 [[이름]] 으로 표시
이름 색 (S1)   상자와 본문 둘 다. 진행자 둘은 한 색(진행자A·진행자V·풀네임), 게스트·발표자는
              사람마다 다른 색. 성만 쓴 자리(Barber·Yuen)와 조사가 붙은 자리(진행자A가)도 칠한다
진행자 부르기  여는 문단에서 풀네임으로 한 번 — 그 뒤 본문·캡션은 진행자A · 진행자V. 원본 파일에는
              이름이 남고(전사 대조용) 생성기가 화면에서 바꾼다. 게스트는 이름 그대로
차례 (S1)      절 제목만 한 칸, 앵커. 눌렀을 때 절 머리 위에 22px 여백.
              **번호는 대단원 「1. 2. 3.」· 그 아래 절 「①②③」**(2026-09-05). 절은 한 줄에
              하나씩 — 「·」로 이으면 절 제목 안의 대시와 섞여 한 문장으로 읽힌다. 들여쓰기는
              머리글 0 · 대단원 6px · 절 16px. 링크 색은 본문 잉크(브라우저 기본 파랑은 회색
              판에서 그 자리만 튄다), 밑줄은 hover 에만.
              보고서 층은 `scratchpad/_rep_toc.py` 의 `toc_html`·`sec_title` 을 부른다 —
              층마다 복사하면 갈린다(넷을 따로 고친 날 나온 규칙). 손으로 짠 층은 같은 파일의
              `check_toc` 가 물고 생성기가 멈춘다. 절 차례가 아닌 안내문은 `rep-note` 로 가른다
절 제목       번호와 제목만. 방법 이름·칩 없음
글자 (S1)      본문 15px / 1.8, 폭 720, 문단 사이 20px. 17px 은 너무 컸다
줄 번호 (S1)   (L97) 은 화면에서 걷는다. 원본 파일에만 남는다
표            바로 위 산문을 되풀이하면 걷는다. 남는 표는 좁은 화면에서도 표로 둔다 —
              행 블록으로 펴지 않는다(아래 「표를 펴지 않는다」). 옆으로는 .tw 안에서 민다
모바일        390px 에서 옆으로 밀리면 생성기가 멈춘다(Playwright)
목록          날짜 옆에는 진행자 말고 다른 참가자만 이름과 짧은 소개. 글 없는 회차·섹션은 안 보인다
```

**표를 펴지 않는다** (2026-09-07 확정) — 좁은 화면에서 `table,thead,tbody,tr,td{display:block}` 으로
행을 카드로 세우고 칸마다 `data-label`·`data-th` 로 열 이름을 얹는 꼴을 쓰지 않는다. 4열 표 한 줄이
카드 한 장이 되면 줄끼리 견주려고 만든 표에서 견줄 것이 사라진다 — 자리 넷을 나란히 놓은 표가
스크롤 넉 장이 됐다. 표는 표로 두고 좁으면 제 상자 안에서 옆으로 민다(`.tw{overflow-x:auto}`).
페이지 자체가 밀리는지는 `check_scroll.js` 가 390px 에서 따로 잰다. **여러 칸에 걸친 것을 보여야
하면 표가 아니라 도해다** — 공정을 칸으로 깔고 누가 어디부터 어디까지 덮는지를 박스로 잡는다
(`seemore_figs.spans`). 규칙은 `check_struct` T1 이 어느 장이든 FAIL 로 문다.


## 2. 확인

- **스크린샷으로 본다.** 검사기가 FAIL 0 이어도 표가 한 글자씩 세로로 늘어진 것, 절 머리가
  화면 위에 붙은 것, 색이 정신 사나운 것, 상자 크기가 제각각인 것은 눈으로만 잡혔다. 데스크톱
  1280 과 모바일 390 을 찍고(`shot_toc.js`), 도해는 한 장씩 찍는다(`shot_figs.js`).
- **라이브도 본다.** 푸시가 곧 배포가 아니다. 2026-09-02 에 다른 세션이 생성기만 커밋하고
  산출물을 안 올려 `gen_site.py` 가 깨끗한 체크아웃에서 죽었고 세 시간 동안 아무도 못 봤다.
  `git archive HEAD` 로 깨끗한 폴더에 풀어 `gen_site.py` 를 돌려 보고, 라이브 페이지의 도해
  수를 curl 로 센다(첫 배포는 푸시 뒤 45초에 올라왔다).
