# 글과 도해 — 확정 규칙 (2026-09-02)

읽는 사람이 하루 동안 Semi Doped 전략 판을 놓고 말한 것을 규칙으로 옮겼다. **새로 쓰는 글과
그림은 이 규칙을 따른다** — 본문은 아래 세 문서로 나눠 뒀고 이 문서는 색인이다. 다른 장(대시보드)과
원문 변환에도 같이 적용한다. 이 문서와 어긋나는
옛 규칙(앞머리 물음·바탕·축, 목차 두 칸, 절 제목의 방법 표기, so-what, 한계 절, 「누가·성격」 열,
임팩트 표)은 그 장의 문서를 고칠 때 이쪽으로 맞춘다.

왜 갈아엎었나 — 저장소의 문서 꼴을 그대로 씌운 판이 「같은 사실이 서너 번 서고 방법 이름이
글을 덮는다. 첫 판이 훨씬 읽기 좋았다」는 말을 들었다.

기계가 잴 수 있는 규칙에는 번호(G·S)가 붙어 있다. `scratchpad/check_semidoped.py` 가 그 번호로
아홉 편을 재고, 생성기가 끝에서 그것을 부르므로 FAIL 이 있으면 커밋 사슬이 끊긴다(아래 「기계가 재는 것」).

## 어디에 무엇이 있나

2026-09-09 에 나눴다. 한 문서에 231줄이 몰려 도해만 80줄이었다 — 고칠 자리를 찾는 데 시간이 들었다.
**규칙 본문은 아래 셋에 있다. 이 문서는 색인과 기계가 재는 것만 남는다.**

```
docs/규칙 — 글.md      독자 · 문체 · 절과 번호 · 용어 · 값 · 글을 받는 절차(모델 고르기 포함)
docs/규칙 — 도해.md    무엇을 그리나 · 값 · 판과 배치 · 선 · 판 위 글자 · 색 · 캡션 · 글과의 관계
docs/규칙 — 화면.md    글 페이지 꼴 · 차례 · 표 · 모바일 · 스크린샷과 라이브 확인
```

장별 규칙 문서(Semi Doped · AI Engineer · 회계사 · M&A)와 스킬은 이 셋을 따른다. **어긋나면 이 셋이 이긴다.**
옛 절 번호로 가리키던 자리는 이렇게 옮겼다 — §1·§2 → 글, §3 → 도해, §4·§5 → 화면, §6 → 글 §3.

## 기계가 재는 것

`scratchpad/check_semidoped.py`. 글과 화면을 같이 본다. 생성기 끝에서 돌아 FAIL 이면 「규칙 위반」을
찍고 멈춘다.

```
G1 길이 5,500~6,500        G2 절 5~7 · 마지막 절 「말하지 않은 것」   G3 여는 문단 「(이하 진행자A)」·V
G4 「N이다」 뒤 ①  (WARN)    G5 영문 인용                          G6 번역체 넷
G7 방법 이름                G8 fixed · people [[이름]]
S1 (L줄) 남음 · 화자 상자 · 차례 · 이름 색 · 15px      S2 도해에 회색 아닌 색
S3 도해가 절 머리에만 (WARN)  S4 글마다 도해 하나 이상
```
못 재는 것 — 중복, 자세, 모듈로 그렸나, 사슬 상자 크기(헬퍼가 보장), 도형 개수. 이건 눈이다.

`check_struct` 의 **T1** 은 이 장만이 아니라 `대시보드/**/*.html` 전부를 본다 — 표를 행 블록으로
펴는 CSS 나 칸에 얹은 열 이름이 있으면 게이트 목록과 무관하게 FAIL 이다. 2026-09-07 에 세우자
워치 상세 19장과 씨모어 2장이 걸렸고 둘 다 고쳤다.

`check_prose` 도 이 장을 본다(2026-09-03 부터 `대시보드/semidoped/*.html` 포함). 그전엔 빠져 있어
대시 밀도(P8)·대구 밀도(P9)·「쪽」 밀도(P15)·은유 서술어(P16)·「가르다·값을 매기다」(P19)가 아홉 편에
한 번도 안 걸렸다 — 넣자 24건이 나왔고 다 고쳤다.


## 이 문서가 아직 안 정한 것

- 번역체 낱말을 `check_prose` 로 옮기는 일. 지금은 이 장의 검사기(G6)에만 있다 — 「열린다」는
  문이 열리는 뜻과 갈라야 해서 「자리·시장·수요 + 열린다」 꼴로만 잡는다.
- 모바일에서 도해 글자가 작은 것(520 판이 350 으로 줄면 10px). 그림이 스무 장쯤 되면 한 번에.
