# 한 편을 도해로 — 번호에서 그림까지

메르 글 한 편을 그림 하나로 줄이는 절차다. 요약을 먼저 쓰고 그림을 나중에 그리지
않는다 — **번호를 붙이고, 합치고, 버리고, 유형을 고른 다음에** 그린다. 그래야 그림이
글보다 세게 주장하지 않는다.

앞선 문서 셋을 전제로 한다.
- `insight-figure` 스킬 — 없는 값 금지·좌표 계산·판 위 글자 금지·검사기
- `docs/도해 유형 — 무엇을 언제 그리나.md` — 유형 다섯과 껍데기 일곱
- `docs/카드 도해 — 그림에서 되읽은 규칙.md` — 우리 그림을 되읽은 규칙

---

## 1단계 — 번호 붙이기 (색인이지 요약이 아니다)

메르는 절반 넘는 글을 **이미 번호로 쓴다**(`1. 미국 국채금리가 계속 오르고 있음.`).
그 번호를 그대로 쓴다. 번호가 없는 글은 문단 단위로 매긴다.

여기서 문장을 고치지 않는다. 원문 구절을 그대로 들고 온다 — 나중에 그림에 들어갈 말이
전부 이 목록에서 나와야 하고, 검사기가 원문과 대조한다.

```
18. 국채 바이백은 재무부가 국채를 되사는 프로그램임
20. 바이백은 단기채를 발행해서 확보한 돈으로 헌 장기채를 되사는 것임
21. 장기채 물량이 줄어드니 장기채를 귀하게 만들 수 있음
```

## 2단계 — 합치기 (연속 번호가 한 동작이면 하나로)

주어가 같고 동작이 같은 연속 번호는 한 마디로 묶는다. **합친 번호를 적어 둔다** —
나중에 「이 마디가 원문 어디냐」를 되짚는 길이 그것뿐이다.

```
18~22 → 「바이백은 만기를 바꾸는 스왑이다」   (재무부가 하는 한 동작)
30~33 → 「원인은 인플레와 재정적자」          (같은 주장의 근거 나열)
```

합칠 때 숫자는 **가장 구체적인 것 하나만** 남긴다. 셋을 다 남기면 그림에서 어느 것이
요점인지 사라진다.

## 3단계 — 버리기 (남길 것은 셋뿐)

남기는 기준은 셋이다. 나머지는 버린다.

| 남긴다 | 버린다 |
|---|---|
| 날짜·수치가 박힌 **사실** | 비유 풀이(현금서비스·루이뷔통 가방) |
| 인과를 잇는 **메커니즘 한 단계** | 배경 설명의 배경 |
| **판단**(한줄 코멘트, 관전포인트) | 여담·인사·다음 글 예고 |

비유는 글이 맡는다. 그림에 비유를 그리면 그 비유가 사실처럼 읽힌다.

목표 부피는 **원문 20~60번 → 마디 6~10개**다. 열을 넘으면 아직 덜 버린 것이고,
다섯 밑이면 그림을 그릴 자리가 아니다(문장이 빠르다).

## 4단계 — 유형 고르기 (물음이 정한다, 자료가 아니라)

3단계에서 남은 마디를 놓고 **이 편이 답하는 물음**을 한 줄로 쓴다. 그 물음이 유형을 정한다.

| 물음 | 유형 | 메르 글 예 |
|---|---|---|
| 누가 누구에게 무엇을 주나 | **A 흐름도**(세로 스택) | 재무부가 되사고 단기채를 찍는다 |
| 누가 더 크냐 / 어디에 몰렸나 | **B 순위 막대** | 중·일·영이 각각 얼마나 줄였나 |
| 한 덩어리가 어떻게 쪼개지나 | **C 구성 막대** | 국채 발행이 단기·중기·장기로 갈리는 몫 |
| 언제부터 얼마나 빨리 | **D 시계열 선** | 30년물이 19년 만의 최고까지 오른 길 |
| 시간에 따라 자원이 어떻게 차나 | **E 일정 띠** | 바이백 회차가 분기에 어떻게 배치되나 |

**항목이 둘이면 그리지 않는다.** A는 주체 셋 이상, B·C는 항목 셋 이상일 때 자리다.
넷 중 어디에도 안 맞으면 표나 문장으로 낸다.

## 5단계 — 값 대조 (그리기 전에)

그림에 들어갈 숫자를 원문에서 하나씩 찾는다. **도형 개수도 값이다** — 막대 셋을 그리면
원문에 항목이 셋이어야 한다.

```bash
PYTHONIOENCODING=utf-8 python -c "
import io,re,sys
svg, src = io.open(sys.argv[1],encoding='utf-8').read(), io.open(sys.argv[2],encoding='utf-8').read()
srcn = re.sub(r'[\s,]','',src)
nums = {n for s in re.findall(r'<text[^>]*>([^<]*)<', svg) for n in re.findall(r'\d[\d,\.]*', s)}
print('못 찾은 값:', [n for n in nums if len(n.replace(',',''))>=2 and n.replace(',','') not in srcn] or '없음')
" <그림 파일> <원문>
```

## 6단계 — 그리기

`scratchpad/epoch_fig.py`의 부품을 쓴다(`box`·`arrow`·`lab`·`role`). 색과 선은
`card_lib` 표준 붓이라 다크모드가 따라온다. 제목은 결론 문장, 부제는 **무엇을 재는지와
기준 시점**, 각주는 겹침·상한·범위·아직 없는 값을 자백한다.

## 한 편에 그림 하나

한 편이 두 물음에 답하면 그림도 둘이다. 그런데 그런 편은 드물다 — 대개는 하나를 고르고
나머지는 카드 본문이 맡는다. **그림이 둘 이상이면 3단계에서 덜 버린 것**이다.

## 되짚기 표

마디마다 원문 번호를 남긴다. 나중에 「이 그림의 이 상자가 어디서 왔나」를 묻는 사람이
있고, 그 답이 없으면 그림을 고칠 수 없다.

| 마디 | 원문 번호 | 인용 |
|---|---|---|
| 바이백은 만기 스왑 | 18~22 | "바이백은 단기채를 발행해서 확보한 돈으로 헌 장기채를 되사는(바이백) 것임" |
