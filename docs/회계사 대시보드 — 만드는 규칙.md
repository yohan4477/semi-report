# 회계사 대시보드 — 만드는 규칙

작성 2026-08-19. 대상은 `대시보드/회계사 대시보드.html` 한 장과 그것을 만드는 파일 넷이다.

```
scratchpad/gen_accountant_dashboard.py   카드 29장 + 섹션 + render() 호출
scratchpad/driver_map.py                 지도 렌더러 (회사에 안 매인다)
scratchpad/driver_map_data.py            삼성전자 지도 데이터
scratchpad/driver_map_data_hynix.py      SK하이닉스 지도 데이터
```

필자 엘곰이 정한 계산 규칙은 여기 없다 — `docs/valuation-rulebook.md`에 있다. 이 문서는
**화면을 어떻게 세우나**만 적는다.

## 1. 화면은 세 겹이다

```
① 타일        회사 이름이 첫 화면이다
   ✦ 전체 보기 29 · 01 삼성전자 005930 23 · 02 SK하이닉스 000660 10 · 03 회사 밖 이야기 4

② 회사 안     버튼 둘만 보인다
   [ 밸류에이션 ]  [ 개별 포스트 N ]

③ 고른 것     밸류에이션이면 지도, 개별 포스트면 카드 목록. 카드를 누르면 본문이 열린다
```

- **회사가 첫 화면이다.** 밸류에이션을 회사 밖에 따로 세우면 삼성전자를 보려고 두 군데를 눌러야 한다
- **회사를 고르면 버튼 둘만.** 지도와 카드 열네 장을 한꺼번에 쏟으면 회사 하나가 스크롤 여러 판이 된다
- 「전체 보기」에서는 지도가 접혀 있다. 거기서는 글이 먼저 나와야 한다(`.sec-lead`)
- 회사 하나로 좁혀지지 않는 글(방법론)은 「회사 밖 이야기」로. 두 회사를 다룬 글은 **양쪽 회사 섹션에 모두** 세운다(`c['also']`)

## 2. 지도 안은 네 겹이다

```
회사 → 시기(연도) → 방법(축) → 그 방법이 무엇을 얼마로 놓았는지
```

- 방법은 여섯이다 — 재무제표 분석 · 간이 DCF · DCF · 역산 · 멀티플 · RIM. 회사마다 있는 것만 세운다
- RIM(잔여이익모형)은 은행지주에만 선다. 예수금이 조달수단이자 대출채권을 만드는 원재료라 잉여현금(FCF)이 안 잡히고, 설비투자도 총자산 700조원에 3,000억원대뿐이라 DCF 산식이 가치창출을 못 담는다. 자기자본 장부가에서 출발해 ROE가 자기자본비용을 웃도는 몫을 더한다
- 한 방법에 글이 여럿이면 날짜 탭으로 가르고 **최신이 맨 왼쪽**이다. 첫 탭이 기본으로 열리므로 축을 누르면 지금 유효한 값이 바로 보인다
- 방법이 사이클 경계를 넘으면 시기로 축을 나눈다(`stmt`/`stmt26`)
- 축 패널 순서: **방법 설명(접힘) → 표 → 계산 사슬 → 드라이버 → 결과 → 주인장 계산(접힘)**
- 주인장 계산은 축 안에 있다. 지도 맨 위에 따로 세우면 「그가 쓴 값」과 「내가 돌린 값」이 다른 층으로 읽혀 같은 DCF를 두 번 설명하게 된다

## 3. 표 규칙

**연도가 가로축이다.** 재무 모형은 왼쪽에서 오른쪽으로 읽는다. 원문 표가 연도를 행으로
두었어도 여기서 뒤집는다.

```
구간   │ 컨센서스 2026~2028 ┃ 필자 2029~2030 ┃ 정상화 2031~2035
연도   │ 2026E 2027E 2028E ┃ 2029E  2030E   ┃ 2031E … 2035E
매출성장률 …
```

- **연도 열 폭은 같다**(`<col>` 98px). 값 길이에 따라 칸이 들쭉날쭉하면 경사가 안 읽힌다
- 폭은 `<col>`만 갖는다. `th`에도 width를 주면 첫 열이 다음 열과 겹쳐 글자가 포개진다
- **구간은 선으로만 가른다.** 한 구간만 칠하면 그 구간이 다른 성격의 값처럼 읽힌다
- **메모는 표 밖, 표 바로 아래에.** 줄 사이에 문장이 들어가면 위아래 숫자가 끊긴다. 연도를 앞세워 잇는다
- 메모 글씨는 숫자보다 작다(10px). 같은 크기면 메모가 표를 먹는다
- **비교와 추이는 표로 낸다.** 여러 회사를 견준 글, 시점이 여럿인 글은 드라이버 칩이 아니라 `VS_TABLES = {축 id: [표]}`로 건다. 칩으로 흩어 놓으면 「ROE 61.17%」가 누구 값인지 칩 안에 묻힌다
- 원문이 「우위」로 표시한 칸만 진하게. 화살표나 색 배지는 안 붙인다

### 3-1. 첫 열 폭 — 표를 만들 때마다 걸린 자리

- **폭은 `<colgroup>`에 못 박는다.** `table-layout:fixed`는 **첫 행**으로 열 폭을 정한다.
  첫 행이 `colspan`을 쓰면(드라이버 이름 줄처럼) 브라우저가 폭을 못 읽고 열을 반반으로
  가른다. `th`에 `width`를 줘도 무시된다 — 2026-08-19에 첫 열이 화면 절반을 먹은 원인이다
- **`<col>`과 `th` 양쪽에 width를 주지 않는다.** 둘을 합쳐 계산해 열 경계가 어긋나고
  첫 열 글자가 다음 열과 포개진다
- 기준 폭
  | 첫 열에 오는 것 | 폭 | 좁은 화면 |
  |---|---|---|
  | 「얼마·근거·왜」 같은 두세 글자 라벨 | 34px | 28px |
  | 「매출성장률」 같은 지표 이름 | 104px | 88px |
- **눈으로 믿지 말고 잰다.** 브라우저에서
  `document.querySelector('.표 th[scope="row"]').getBoundingClientRect().width`.
  CSS에 적힌 값과 다르면 위 두 함정 중 하나다
- 지금 `table-layout:fixed`를 쓰는 표는 둘뿐이다 — 연도 표(`.dm-ep-wide`)와 드라이버
  표(`.dm-dvt`). 둘 다 `colgroup`을 갖고 있다. 새 표에 fixed를 쓰면 colgroup도 같이 넣는다

## 4. 값 규칙

- **원문에 있는 값만 쓴다.** 없는 칸은 비우고 비었다는 사실을 적는다. 사이를 채우려면 지어내야 한다
- **원문 표가 이미지면 떠서 읽는다.** 네이버 스마트에디터 글은 표를 이미지로 넣는 경우가 많아 클리핑 텍스트에 안 잡힌다. CDP로 그 이미지 영역만 스크린샷을 떠서 값을 옮긴다 — 2026-08-19에 「컨센서스가 얼마냐」에 답이 없던 원인이 이것이었다
- **T1~T10 같은 표기는 연도로 바꾼다.** 평가 시점이 1년차다. 원문이 연도를 병기했으면 그대로, 아니면 매핑을 밝힌다
- `basis`를 정확히 단다 — 필자가 이유를 밝힌 값(`author`)·실적(`history`)·외부 인용(`quoted`)·근거 없음(`none`)
- 주인장이 다시 계산한 값은 `by='ours'`로 달아 필자 값과 화면에서 가른다. **새 가정을 넣지 않는다** — 그가 낸 숫자끼리 나누고 곱하는 것까지다

## 5. 기계가 막는 것

`dash_common.render()`가 페이지를 쓰기 전에 검사한다. 어기면 파일이 안 나간다.

| 검사 | 무엇을 막나 |
|---|---|
| `check_ui` | 첫 화면이 섹션 타일이 아닌 것, 관문 버튼, 롤업이 타일보다 위에 오는 것 |
| `check_labels` | 라벨에 있는 회사가 원문·제목에 없는 것, 여러 회사를 다룬 원문을 한 회사 라벨 아래 두는 것 |
| `check_links` | 카드가 가리키는 저장소 파일이 없는 것(요약본 제목을 한 글자 고치면 404가 된다) |

그 밖에 산문은 `insights/check_prose.py`가 본다(대시보드 HTML까지). 푸시 전에는 검사기
다섯을 전부 돌린다 — `check_notes` · `check_prose` · `check_read` · `check_cite` · `check_fresh`.

## 6. 새 회사를 붙일 때

1. `scratchpad/driver_map_data_<회사>.py`를 만든다. 형식은 삼성전자 모듈을 따른다
2. 축은 있는 것만 세운다. 평가가 한 편뿐이면 축도 하나다 — 억지로 채우지 않는다
3. 판정 파일(`insights/valuation/<티커>-<회사>/judgment.json`)이 없으면 `judgment_dir=None`으로 그 층을 건너뛴다
4. `gen_accountant_dashboard.py`에 섹션과 `sec_top`을 더한다
5. 지도가 한 페이지에 여럿이므로 id 접두어가 갈리는지 확인한다 — 생성된 HTML에서 중복 `id` 0개
