**Goal:** 색인이 가리키는 줄 11,910개마다 「그 줄이 언제를 말하나」를 붙이고, 그것을 쓴 날과 견주어 회고·현재·전망으로 가른 뒤, 낡음 판정을 현재와 전망 줄에만 먹인다.

**Architecture:** 파일 단위 사실(쓴 날·신선도 갈래)과 줄 단위 판정(가리키는 때·시제)을 가른다. `utterance.py`가 `manifest.json`과 파일 이름에서 쓴 날을 풀고, `times.py`가 줄 하나와 쓴 날만 받아 때를 뽑는 순수 함수이며, `gen_times.py`가 색인이 가리키는 줄만 훑어 `times.json`을 낸다. `times.json`은 희소하다 — 명시되거나 계산된 줄만 적고 상속은 조회할 때 채운다.

**Tech Stack:** Python 3.13 표준 라이브러리만. 테스트는 pytest. 새 의존성 없음.

## Global Constraints

- **표준 라이브러리만 쓴다.** 새 패키지를 추가하지 않는다
- **콘솔이 cp949다.** 모든 파이썬 실행에 `PYTHONIOENCODING=utf-8`을 붙인다. 파일 입출력은 전부 `io.open(..., encoding='utf-8')`으로 연다
- **판정은 결정적이다.** 같은 줄과 같은 쓴 날에서 같은 답이 나와야 한다. 딕셔너리 순회 순서에 기대지 말고 정렬한다
- **`times.json`은 상속을 안 적는다.** 명시·계산만 적는다. 없는 것을 안 적어야 「이건 상속이다」가 저절로 구분된다
- **신선도 표를 복제하지 않는다.** `check_fresh.STALE_DAYS`를 import해서 쓴다. 같은 일을 하는 코드가 둘이면 하나가 낡는다
- **회고 줄에 신선도를 안 먹인다.** 1965년에 일어난 일은 2026년에도 그대로다
- **조회는 읽기 전용이다.** `q.py`는 어떤 파일도 쓰지 않는다
- **경로를 찍어서 스테이징한다.** `git add -A`를 쓰지 않는다. 저장소를 다른 세션과 공유한다
- **이 계획의 범위는 spec 4단뿐이다.** 영문 원본 확장(5단), 동시출현 그래프·연표(6단), 축 검토기(7단), 벡터(8단)는 넣지 않는다

## 실측 — 이 계획이 서 있는 숫자

전부 워크트리 `.claude/worktrees/entity-index` 커밋 `fb3636c`에서 쟀다. 메인 체크아웃에는 다른 세션의 미커밋 작업이 섞인다.

```
코퍼스                       content/**/*.md 478편 · 88,900줄
색인이 가리키는 서로 다른 줄     11,910
그중 「YYYY년」이 든 줄         1,643 (13.8%)
  한 줄에 연도 1개              1,201
  2개 331 · 3개 78 · 4개 24 · 5개 8 · 6개 1   (둘 이상 442줄, 27%)
「N년 전/뒤/후」가 든 줄         174
「작년·재작년·지난해·올해·금년·내년」이 든 줄   183
「YYYY년대」가 든 줄            59
```

쓴 날은 두 곳에서 온다.

```
manifest.json 의 date 가 있는 코퍼스 파일     364 / 478
그것이 없고 파일 이름에서 뽑히는 것            108
합                                        472 / 478
남은 6편은 쓴 날을 모른다
```

코퍼스 전체(색인 줄 아닌 것까지)의 상대 표현 빈도는 이렇다 — 지금 900, 현재 799, 최근 368, 앞으로 179, 올해 175, 향후 174, 작년 97, 내년 47, 지난해 23, 재작년 3. **「지금·현재·최근·앞으로·향후」는 계산이 안 된다.** 연도로 풀 수 없으므로 이 계획은 건드리지 않는다. 그런 줄은 표지가 없는 줄과 똑같이 상속으로 떨어지고 시제는 현재가 된다.

연도 범위는 1900~2064였고 전수로 확인하니 전부 진짜였다(크레스트몬트 1900년 이후 S&P 구간, 라이트 형제 1903년, 2050년 전망). **바깥값 검사는 정규식 사고를 잡는 그물이지 자료를 거르는 체가 아니다.** 그래서 경계를 넓게 잡는다.

## 이 계획이 내리는 판단 셋

실측만으로 안 정해지는 자리가 셋이다. 아래대로 정하고 근거를 적어 둔다.

**한 줄에 연도가 둘 이상이면 가장 늦은 것을 잡는다.** 442줄이 그렇다. 늦은 쪽을 잡는 이유는 시제가 낡음 판정을 가르기 때문이다 — 「2018년부터 2028년까지」를 1분위 연도로 잡아 회고로 두면 앞날 주장이 신선도 검사를 통째로 빠져나간다. 대신 최소 연도가 다르면 `span`에 함께 적어 6단 연표가 구간으로 그릴 수 있게 한다.

**명시가 계산을 이긴다.** 한 줄에 「2020년」과 「작년」이 같이 있으면 명시로 본다. 계산은 쓴 날이라는 한 겹을 더 거치므로 틀릴 자리가 하나 더 있다.

**신선도 갈래는 `manifest.categories`에서 표로 옮긴다.** `check_fresh`의 `STALE_DAYS`는 biz·chip·model·power 넷인데 매니페스트의 categories는 주제 폴더 이름(회계사·AI Engineer·ai-infra/compute…)이다. 둘을 잇는 표를 `utterance.SECTION` 한 곳에 두고, 표에 없는 갈래는 `DEFAULT_STALE` 180일로 떨어뜨린다. 표가 판단이고 코드는 표를 읽을 뿐이다.

## File Structure

| 파일 | 책임 |
|---|---|
| `insights/paths.py` (수정) | 경로 상수 `TIMES` 추가 |
| `insights/utterance.py` (신규) | 파일 단위 시간 사실 — 쓴 날과 신선도 갈래. `manifest.json`과 파일 이름만 읽는다. 본문은 안 읽는다 |
| `insights/times.py` (신규) | 줄 하나에서 때를 뽑는 순수 함수. 파일도 코퍼스도 모른다. 판정 규칙이 전부 여기 있다 |
| `insights/gen_times.py` (신규) | 색인이 가리키는 줄만 훑어 `times.json`을 쓴다 |
| `insights/times.json` (생성물) | 줄 주소 → 가리키는 때·확실도·시제. 커밋한다 |
| `insights/check_index.py` (수정) | X6·X7·X8 추가 |
| `scripts/q.py` (수정) | 조회 결과에 시제·때·확실도·낡음을 붙인다 |
| `scripts/build_all.py` (수정) | 생성기 목록에 `gen_times.py` 등록 |

`times.py`를 `gen_times.py`에서 가른 이유는 1단계에서 `matcher.py`를 가른 이유와 같다. 판정 규칙은 오탐이 나오는 자리라 테스트를 촘촘히 박아야 하는데, 파일 입출력이 섞이면 테스트마다 임시 파일을 만들어야 한다. 규칙을 순수 함수로 떼면 문자열과 날짜만 넣고 테스트한다.

`utterance.py`를 따로 둔 이유는 쓴 날이 두 군데에서 필요하기 때문이다 — `gen_times.py`가 계산에 쓰고 `q.py`가 상속에 쓴다.

```python
# -*- coding: utf-8 -*-
"""파일 하나에 딸린 시간 사실 — 쓴 날과 신선도 갈래. 본문은 안 읽는다.

쓴 날은 두 곳에서 온다. manifest.json 의 date 가 첫째고, 비어 있으면 파일 이름의
[YYMMDD] 나 YYYY-MM-DD 를 쓴다. 코퍼스 478편 중 매니페스트가 364편을 덮고
이름이 108편을 더 덮어 472편이 된다. 남은 6편은 쓴 날을 모르고, 그 줄은
times.json 에 안 들어간다 — 기준이 없으면 상대 표현도 시제도 못 푼다.

SECTION 은 판단이다. check_fresh 의 STALE_DAYS 는 biz·chip·model·power 넷인데
매니페스트의 categories 는 주제 폴더 이름이라 둘을 손으로 이어야 한다.
표를 여기 한 곳에 두고 코드는 표를 읽기만 한다.
"""
import io
import json
import os
import re

NAME_ISO = re.compile(r'(20\d{2})-(\d{2})-(\d{2})')
NAME_6 = re.compile(r'\[(\d{2})(\d{2})(\d{2})\]')
NAME_4 = re.compile(r'\[(\d{2})(\d{2})\]')

SECTION = {
    # 값과 물량 — 분기면 뒤집힌다
    'ai-infra/business': 'biz',
    '회계사': 'biz',
    '미국주식 사관학교': 'biz',
    '부동산': 'biz',
    # 칩 세대와 벤치마크
    'ai-infra/compute': 'chip',
    'ai-infra/memory': 'chip',
    'ai-infra/networking': 'chip',
    'semiconductor': 'chip',
    'semiconductors': 'chip',
    # 모델과 학습 기법
    'ai-models': 'model',
    'ai-models/agents': 'model',
    'ai-models/rl': 'model',
    'AI Engineer': 'model',
    '피지컬AI': 'model',
    'physical-ai': 'model',
    # 전력망과 건물 — 연 단위로 움직인다
    'ai-infra/power': 'power',
    'ai-infra/construction': 'power',
    'power': 'power',
    'oil-geopolitics': 'power',
    'oil-supplychain': 'power',
}


def name_date(rel):
    base = rel.rsplit('/', 1)[-1]
    m = NAME_ISO.search(base)
    if m:
        return '%s-%s-%s' % m.groups()
    m = NAME_6.search(base)
    if m:
        y, mo, d = m.groups()
        return '20%s-%s-%s' % (y, mo, d)
    m = NAME_4.search(base)
    if m:
        y, mo = m.groups()
        return '20%s-%s-01' % (y, mo)
    return ''


def section_for(categories):
    for c in (categories or []):
        if c in SECTION:
            return SECTION[c]
    return ''


def load(root, manifest_path=None):
    p = manifest_path or os.path.join(root, 'insights', 'manifest.json')
    with io.open(p, encoding='utf-8') as f:
        rows = json.load(f).get('sources') or []
    out = {}
    for s in rows:
        rel = str(s.get('path') or '')
        if not rel:
            continue
        out[rel] = {
            'date': str(s.get('date') or '') or name_date(rel),
            'section': section_for(s.get('categories')),
        }
    return out


def date_of(meta, rel):
    m = meta.get(rel) or {}
    return m.get('date') or name_date(rel)


def section_of(meta, rel):
    return (meta.get(rel) or {}).get('section', '')
```

  - `times.computed(line: str, utter_year: int) -> list[int]` — 상대 표현을 쓴 날 기준으로 푼 연도
  - `times.tense_of(t: int, utter_year: int) -> str` — `'회고'|'현재'|'전망'`

`span`은 그 줄에 연도가 둘 이상이고 최소가 최대와 다를 때만 넣는다.

# -*- coding: utf-8 -*-
"""줄 하나가 가리키는 때. 파일도 코퍼스도 모른다 — 문자열과 쓴 날만 받는다.

셋으로 푼다.
  명시  「1965년」          정규식으로 그대로 읽는다. 색인 줄 1,643개가 그렇다
  계산  「작년」「3년 전」    쓴 날에서 빼고 더한다. 판단이 필요 없다
  없음  아무 표지도 없으면 None 을 낸다. 상속은 여기서 안 한다 —
        조회할 때 쓴 날로 채우고, 그래야 「이건 상속이다」가 저절로 구분된다

한 줄에 연도가 둘 이상이면 t 는 가장 늦은 연도다. 색인 줄 1,643개 중 442개가
그렇다. 늦은 쪽을 잡는 이유는 시제가 낡음 판정을 가르기 때문이다 —
「2018년부터 2028년까지」를 회고로 두면 앞날 주장이 신선도 검사를 빠져나간다.
대신 최소 연도가 다르면 span 에 함께 적어 연표가 구간으로 그릴 수 있게 한다.

「지금·현재·최근·앞으로·향후」는 여기서 안 다룬다. 연도로 안 풀리기 때문이다.
그런 줄은 표지가 없는 줄과 똑같이 상속으로 떨어진다.
"""
import re

YEAR = re.compile(r'(?<![0-9])((?:19|20)\d{2})\s*년')
OFFSET = re.compile(r'(?<![0-9])(\d{1,2})\s*년\s*(전|뒤|후)')

# 긴 말을 먼저 걷어낸다 — 「작년」이 「재작년」 안에 들어 있다
LONG_WORDS = (('재작년', -2), ('내후년', 2))
WORDS = (('작년', -1), ('지난해', -1), ('올해', 0), ('금년', 0), ('내년', 1))

LOW = 1850          # 이보다 이르면 정규식이 헛것을 잡은 것이다
AHEAD = 50          # 쓴 날 연도 + 이만큼까지 앞날 주장으로 성립한다고 본다


def explicit(line):
    return sorted({int(y) for y in YEAR.findall(line)})


def computed(line, utter_year):
    out = set()
    rest = line
    for word, delta in LONG_WORDS:
        if word in rest:
            out.add(utter_year + delta)
            rest = rest.replace(word, ' ')
    for word, delta in WORDS:
        if word in rest:
            out.add(utter_year + delta)
    for n, direction in OFFSET.findall(line):
        n = int(n)
        out.add(utter_year - n if direction == '전' else utter_year + n)
    return sorted(out)


def tense_of(t, utter_year):
    if t < utter_year:
        return '회고'
    if t > utter_year:
        return '전망'
    return '현재'


def find(line, utter_date):
    if not utter_date or len(utter_date) < 4 or not utter_date[:4].isdigit():
        return None
    uy = int(utter_date[:4])
    years = explicit(line)
    how = '명시'
    if not years:
        years = computed(line, uy)
        how = '계산'
    years = [y for y in years if LOW <= y <= uy + AHEAD]
    if not years:
        return None
    t = max(years)
    out = {'t': '%d' % t, 'how': how, 'tense': tense_of(t, uy)}
    if min(years) != t:
        out['span'] = ['%d' % min(years), '%d' % t]
    return out
```

**`OFFSET`의 앞 lookbehind가 왜 있나.** 없으면 「1965년 전후로」에서 `65년 전`이 잡혀 2026-65=1961이 나온다. 앞에 숫자가 오면 매칭이 아니라고 못 박아 막는다.

**`computed`가 `OFFSET`을 `line`에서 찾는 이유.** `rest`는 「재작년」을 지운 문자열이라 자리가 밀린다. 숫자 오프셋은 낱말 마스킹과 무관하므로 원문에서 찾는다.

# -*- coding: utf-8 -*-
"""times.json — 색인이 가리키는 줄만 훑어 가리키는 때를 적는다.

희소하게 둔다. 명시되거나 계산된 줄만 적고 상속은 안 적는다. 상속은 조회할 때
쓴 날로 채운다. 없는 것을 안 적어야 파일이 작고 「이건 상속이다」가 구분된다.

코퍼스 88,900줄을 다 훑지 않고 색인이 가리키는 11,910줄만 본다. 개체가 안 나온
줄은 조회에 안 실리므로 때를 매길 이유가 없다.

  py -3.13 insights/gen_times.py
"""
import collections
import datetime
import io
import json
import os
import sys

sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))
import paths  # noqa: E402
import times  # noqa: E402
import utterance as ut  # noqa: E402


def indexed_lines(idx):
    by = collections.defaultdict(set)
    for name, addrs in idx.items():
        if name == '_meta':
            continue
        for a in addrs:
            rel, _, num = a.rpartition('#L')
            if num.isdigit():
                by[rel].add(int(num))
    return by


def build(root, idx, meta):
    by = indexed_lines(idx)
    hits = {}
    for rel in sorted(by):
        utter = ut.date_of(meta, rel)
        if not utter:
            continue
        full = os.path.join(root, rel.replace('/', os.sep))
        if not os.path.isfile(full):
            continue
        nums = by[rel]
        with io.open(full, encoding='utf-8', errors='replace') as f:
            for n, line in enumerate(f, 1):
                if n not in nums:
                    continue
                got = times.find(line, utter)
                if got:
                    hits['%s#L%d' % (rel, n)] = got
    out = {'_meta': {
        'built': datetime.date.today().isoformat(),
        'index_fingerprint': (idx.get('_meta') or {}).get('fingerprint', ''),
        'lines': len(hits),
    }}
    for k in sorted(hits):
        out[k] = hits[k]
    return out


def main():
    with io.open(paths.INDEX, encoding='utf-8') as f:
        idx = json.load(f)
    meta = ut.load(paths.ROOT)
    out = build(paths.ROOT, idx, meta)
    with io.open(paths.TIMES, 'w', encoding='utf-8', newline='\n') as f:
        json.dump(out, f, ensure_ascii=False, indent=0, sort_keys=True)
        f.write('\n')
    how = collections.Counter()
    tense = collections.Counter()
    for k, v in out.items():
        if k == '_meta':
            continue
        how[v['how']] += 1
        tense[v['tense']] += 1
    print('때를 매긴 줄 %d — %s' % (out['_meta']['lines'],
          ' · '.join('%s %d' % (k, how[k]) for k in sorted(how))))
    print('시제 — %s' % ' · '.join('%s %d' % (k, tense[k]) for k in sorted(tense)))
    return 0


if __name__ == '__main__':
    sys.exit(main())
```

def stale_limit(section):
    return check_fresh.STALE_DAYS.get(section, check_fresh.DEFAULT_STALE)


def _days_between(a, b):
    """'YYYY-MM-DD' 둘 사이의 날수. 꼴이 어긋나면 0."""
    try:
        x = datetime.date(*map(int, a.split('-')))
        y = datetime.date(*map(int, b.split('-')))
    except (ValueError, TypeError):
        return 0
    return (y - x).days


def _time_of(addr, tmap, meta, today):
    """그 줄의 때·확실도·시제·낡음. tmap 에 없으면 쓴 날을 상속한다."""
    rel = addr.rpartition('#L')[0]
    utter = ut.date_of(meta, rel)
    got = (tmap or {}).get(addr)
    if got:
        t, how, tense = got.get('t', ''), got.get('how', ''), got.get('tense', '')
    elif utter[:4].isdigit():
        t, how, tense = utter[:4], '상속', '현재'
    else:
        t, how, tense = '', '상속', '현재'
    stale = False
    if tense in ('현재', '전망') and utter and today:
        age = _days_between(utter, today)
        stale = age > stale_limit(ut.section_of(meta, rel))
    return {'t': t, 'how': how, 'tense': tense, 'utter': utter, 'stale': stale}

def lookup(root, idx, name, cap=CAP, tmap=None, meta=None, today=None):
    addrs = idx.get(name) or []
    imeta = idx.get('_meta') or {}
    meta = meta or {}
    shown = addrs[:cap]
    rows = []
    counts = {}
    for addr in shown:
        rel, _, num = addr.rpartition('#L')
        row = {'addr': addr,
               'text': read_line(root, rel, int(num)) if num.isdigit() else ''}
        row.update(_time_of(addr, tmap, meta, today))
        counts[row['tense']] = counts.get(row['tense'], 0) + 1
        rows.append(row)
    return {
        'name': name,
        'total': len(addrs),
        'shown': len(shown),
        'cut': len(addrs) - len(shown),
        'files': len({a.rpartition('#L')[0] for a in addrs}),
        'built': imeta.get('built', ''),
        'fingerprint': imeta.get('fingerprint', ''),
        'tense_counts': counts,
        'rows': rows,
    }

def render(r):
    out = ['%s · 원문 %d편 · %d줄' % (r['name'], r['files'], r['total'])]
    for i, row in enumerate(r['rows'], 1):
        mark = ' 낡음' if row.get('stale') else ''
        out.append('  [%d] %s %s  (쓴 날 %s, %s)%s  %s'
                   % (i, row.get('tense', ''), row.get('t', '') or '—',
                      row.get('utter', '') or '모름', row.get('how', ''),
                      mark, row['addr']))
        if row['text']:
            out.append('      %s' % row['text'][:120])
    counts = r.get('tense_counts') or {}
    tense = ' · '.join('%s %d' % (k, counts[k]) for k in sorted(counts)) or '—'
    out.append('  — 영수증 — 색인 %s (%s) · 본 줄 %d · 잘림 %d · 시제 %s'
               % (r['built'], r['fingerprint'][:8], r['shown'], r['cut'], tense))
