**Goal:** 색인 대상을 `content/` 478편에서 `input/clippings`의 영문 원본 75편과 메르 클리핑 364편까지 넓히고, 갈래마다 다른 파일 꼴에서 줄을 뽑는 일을 한 곳으로 모은다.

**Architecture:** 지금 줄을 읽는 코드가 네 군데에 흩어져 있고 넷 다 「파일을 열어 한 줄씩 읽는다」를 가정한다. 메르 클리핑은 그 가정이 깨진다 — 물리 줄이 14개인데 본문은 `text` 문자열 하나 안에 105줄이 들어 있다. `source_lines.py`를 세워 「원문 하나에서 줄 목록을 뽑는다」를 한 곳에 두고 네 군데가 그것을 쓰게 한다. 주소 꼴 `경로#L123`은 그대로 두고 뜻만 「그 원문의 123번째 줄」로 넓힌다.

**Tech Stack:** Python 3.13 표준 라이브러리만. 테스트는 pytest. 새 의존성 없음.

**Spec:** `docs/superpowers/specs/2026-08-27-개체-색인과-축-검토기-design.md` 5단

## Global Constraints

- **표준 라이브러리만 쓴다.** 새 패키지를 추가하지 않는다
- **콘솔이 cp949다.** 모든 파이썬 실행에 `PYTHONIOENCODING=utf-8`을 붙인다. 파일 입출력은 전부 `io.open(..., encoding='utf-8')`으로 연다
- **주소 꼴을 안 바꾼다.** `경로#L123` 하나다. 갈래마다 다른 꼴(`#T88` 같은 것)을 만들지 않는다 — 조회·검사·때가 전부 이 꼴에 걸려 있고, 갈래를 아는 것은 `source_lines` 하나면 된다
- **줄을 읽는 코드를 새로 만들지 않는다.** 이 계획이 끝나면 원문에서 줄을 뽑는 자리는 `source_lines.py` 하나뿐이어야 한다
- **매칭은 결정적이다.** 딕셔너리 순회 순서에 기대지 말고 정렬한다
- **증분을 깨뜨리지 않는다.** `_meta.files_stat`의 `[해시, 줄 수]`에서 줄 수는 `source_lines` 기준이다. 물리 줄 수와 섞이면 증분이 조용히 어긋난다
- **경로를 찍어서 스테이징한다.** `git add -A`를 쓰지 않는다. 저장소를 다른 세션과 공유한다
- **이 계획의 범위는 spec 5단뿐이다.** 동시출현 그래프와 연표(6단), 축 검토기(7단), 벡터(8단)는 넣지 않는다

```python
# -*- coding: utf-8 -*-
"""원문 하나에서 줄을 뽑는다. 갈래별 차이가 전부 여기 있다.

색인 주소는 갈래와 무관하게 `경로#L123` 하나다. 「123번째 줄」이 무엇인지만
갈래마다 다르다.

  .md    파일의 물리 줄 그대로
  .json  메르 클리핑. 본문이 text 문자열 하나에 들어 있어 물리 줄이 14개뿐이고
         그 안에 105줄이 escape 로 접혀 있다. text 를 펴서 그 줄을 쓴다

이 파일이 서기 전에는 줄을 읽는 코드가 gen_index·gen_times·q·check_index 넷에
흩어져 있었다. 넷 다 「파일을 열어 한 줄씩」을 가정했고 메르에서 그 가정이 깨진다.
한 곳만 고치면 나머지 셋이 조용히 어긋나므로 모았다.
"""
import io
import json
import os

MARKDOWN = '.md'
CLIPPING = '.json'


def known(rel):
    return os.path.splitext(rel)[1].lower() in (MARKDOWN, CLIPPING)


def _full(root, rel):
    return os.path.join(root, rel.replace('/', os.sep))


def lines(root, rel):
    path = _full(root, rel)
    if not os.path.isfile(path):
        return []
    ext = os.path.splitext(rel)[1].lower()
    if ext == CLIPPING:
        try:
            with io.open(path, encoding='utf-8') as f:
                body = json.load(f).get('text') or ''
        except (ValueError, AttributeError):
            return []
        return body.split('\n') if body else []
    with io.open(path, encoding='utf-8', errors='replace') as f:
        text = f.read()
    if not text:
        return []
    out = text.split('\n')
    if out and out[-1] == '':
        out.pop()
    return out


def count(root, rel):
    return len(lines(root, rel))


def line_at(root, rel, n):
    got = lines(root, rel)
    if n < 1 or n > len(got):
        return ''
    return got[n - 1].strip()
```

**마지막 빈 조각을 떼는 까닭.** 기존 `gen_index.scan`은 `for n, line in enumerate(f, 1)`로 셌고, 파일이 개행으로 끝나면 마지막 개행 뒤에는 줄이 없다. `split('\n')`은 거기서 빈 조각을 하나 더 만든다. 그것을 안 떼면 모든 파일의 줄 수가 1씩 늘고 증분의 `files_stat`이 어긋난다.

```python
    """그 파일들만 훑는다. -> (개체 -> 주소 목록, 파일 -> 줄 수)"""
    rules = mt.compile_rules(rows)

        counts[rel] = len(got)
        for n, line in enumerate(got, 1):
            for c in mt.find(line, rules):
```

```python
import glob

FM_PUBLISHED = re.compile(r'^published:\s*(\d{4}-\d{2}-\d{2})\s*$', re.M)
FM_CREATED = re.compile(r'^created:\s*(\d{4}-\d{2}-\d{2})\s*$', re.M)
JSON_DATE = re.compile(r'"date"\s*:\s*"(\d{4}-\d{2}-\d{2})"')
CLIPS = ('input/clippings/*.md', 'input/clippings/mer/*.json')


def clipping_date(root, rel):
    path = os.path.join(root, rel.replace('/', os.sep))
    if not os.path.isfile(path):
        return ''
    with io.open(path, encoding='utf-8', errors='replace') as f:
        head = f.read(2000)
    if rel.lower().endswith('.json'):
        m = JSON_DATE.search(head)
        return m.group(1) if m else ''
    m = FM_PUBLISHED.search(head) or FM_CREATED.search(head)
    return m.group(1) if m else ''
```

```python
# -*- coding: utf-8 -*-
"""영한 이름 매핑 후보를 캔다. 사전에 넣지는 않는다 — 사람이 고른다.

이 저장소는 「용어는 남기고 첫 등장에 괄호로 푼다」를 규칙으로 쓴다. 그래서 본문에
「도쿄일렉트론(TEL)」 꼴이 쌓여 있고, 그것이 곧 영한 매핑이다. 다만 같은 괄호가
학회 이름·일반 용어·종목 기호에도 쓰여서 캐낸 것을 그대로 믿으면 안 된다.
연도가 든 풀이만 기계가 걸러 내고 나머지 판단은 사람에게 넘긴다.

  py -3.13 scripts/mine_pairs.py
"""
import collections
import os
import re
import sys

ROOT = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
sys.path.insert(0, os.path.join(ROOT, 'insights'))
import entities_lib as el  # noqa: E402
import gen_index as gi  # noqa: E402
import paths  # noqa: E402
import source_lines as sl  # noqa: E402

GLOSS = re.compile(
    r'([가-힣][가-힣A-Za-z0-9]{1,15})'
    r'\s*\(\s*([A-Za-z][A-Za-z0-9&.\- ]{1,30}?)\s*\)')
YEAR = re.compile(r'(?:19|20)\d{2}')


def pairs_in(line):
    out = []
    for ko, en in GLOSS.findall(line):
        en = en.strip()
        if not en or YEAR.search(en):
            continue
        out.append((ko, en))
    return out


def mine(root, files, need):
    got = collections.Counter()
    for rel in files:
        for line in sl.lines(root, rel):
            for ko, en in pairs_in(line):
                if ko in need:
                    got[(ko, en)] += 1
    return dict(got)


def main():
    rows = el.load()
    need = {r['canonical'] for r in rows if not r.get('en')}
    got = mine(paths.ROOT, gi.corpus_files(paths.ROOT), need)
    order = sorted(got.items(), key=lambda kv: (-kv[1], kv[0]))
    covered = {ko for (ko, _) in got}
    print('짝 %d종 · en 없는 개체 %d종 중 %d종을 덮는다'
          % (len(got), len(need), len(covered)))
    print()
    for (ko, en), n in order:
        print('%-16s %-30s %d' % (ko, en, n))
    return 0


if __name__ == '__main__':
    sys.exit(main())
```

**`GLOSS`의 뒤 수량자가 게으른(`?`) 까닭.** 욕심쟁이면 `시놉시스(Synopsys)와 케이던스(Cadence)`에서 첫 여는 괄호와 마지막 닫는 괄호를 물어 한 짝으로 뭉갠다. 짝이 둘인 줄이 실제로 있다.

**`YEAR`만 기계가 거르는 까닭.** 「인텔(ISSCC 2026)」·「케이던스(VLSI 2025)」는 학회와 해라서 이름이 아니고, 연도가 든 풀이는 예외 없이 그렇다. 「브로드컴(ASIC)」·「주성엔지니어링(ALD)」은 일반 용어인데 꼴만으로는 `도쿄일렉트론(TEL)`과 구분이 안 된다. 규칙으로 못 가르는 것을 규칙으로 가르려 들면 진짜 매핑까지 잃는다.
