# 본보기 — 「AI 데이터센터 투자는 회수되는가」를 실제로 구조화한 것

`2026-08-27-구조-도구-design.md` 가 규칙이라면 이 문서는 그 규칙으로 한 바퀴 돈 결과다.
코드도 숫자 세기도 안 들어갔다. 손으로 짠 것이고, 도구가 내야 할 산출물이 이 모양이다.

## 0. 물음을 먼저 벼린다

「AI 데이터센터 투자는 회수되는가」는 그대로는 답이 안 나온다. 누구 투자인지, 언제까지인지,
회수를 무엇으로 재는지가 없다.

> **2025~26년에 착공한 AI 데이터센터 한 동이, 그 안 GPU 의 감가상각 기간(6년) 안에
> 투입 자본을 회수하는가**

시계가 생겼고 판정이 가능해졌다. **이 단계를 건너뛰면 아래가 전부 헛돈다.**

## 1. 레벨 1 을 셋으로 연다

**[A] 수식** — 회수 = 누적 현금유입 − 투입. 크기를 잰다. 숫자가 있어야 돌아간다.

**[B] 프로세스(고리)** — 조달 → 건설 → 가동 → 매출 → 재조달. 어디서 끊기나.
마지막이 처음을 먹이는 고리다. 매출이 다음 라운드 조달을 정당화하는 구조라 한 바퀴가
안 돌면 전체가 선다.

**[C] 행위자** — 칩회사 / 네오클라우드 / 하이퍼스케일러 / 모델회사 / 전력회사.
누가 남기고 누가 뒤집어쓰나.

**[C] 를 먼저 편다.** 이유가 구조적이다 — 주체마다 답이 다르면 **물음 자체가 틀린 것**이다.
칩회사는 이미 회수했고 네오클라우드가 뒤집어쓰는 구조라면 「회수되는가」를 통으로 물으면
안 되고 주체별로 쪼개야 한다. **가장 크게 지우는 컷이 먼저다.**

## 2. 행위자로 열고 대부분을 쳐낸다

| 주체 | 회수 시점 | 판정 |
|---|---|---|
| 칩회사 | 출하 시점에 현금 | 이미 회수. 잘라 냄 |
| 전력회사 | 장기계약 고정가 | 위험이 낮다. 잘라 냄 |
| 하이퍼스케일러 | 자기 현금흐름으로 부담 | 자기자본이라 파산 경로가 아님. 보류 |
| **네오클라우드** | 빌린 돈으로 사서 임대 | **여기가 문제다** |
| 모델회사 | 컴퓨트를 사는 쪽 | 네오클라우드의 고객. 아래에 붙는다 |

다섯 중 셋이 한 단에서 잘렸다. **이것이 MECE 의 값이다** — 겹치지 않으니 「칩회사는
아니다」가 유효한 소거가 된다.

## 3. 한 가지를 판다 — 여기서 형이 바뀐다

```
네오클라우드가 6년 안에 회수하나
└ 수식     회수 = 계약매출 − (부채상환 + 전력 + 감가상각)
  ├ 계약매출
  │ └ 구성   장기계약분 / 스팟분
  │   └ 장기계약분
  │     └ 인과   고객은 모델회사 → 모델회사 자금이 마르면 계약이 깨진다
  │              → 계약매출이 장부에만 남는다
  ├ 부채상환
  │ └ 구성   원금 / 이자 / 담보조건
  │   └ 담보조건
  │     └ 인과   담보가 GPU 자체 → 중고값이 무너지면 추가담보 요구
  │              → 그 시점에 현금이 없다
  ├ 전력      ← 1단에서 멈춤. 장기 고정가라 불확실성이 낮다
  └ 감가상각
    └ 대립     6년이냐 3년이냐 — 가정 하나가 결론을 뒤집는다
```

수식 안에 구성이 들고 그 안에 인과가 들었다. **뎁스가 제각각이다** — 전력은 1단,
계약매출은 4단. 전력은 계약으로 묶여 불확실성이 낮으니 더 팔 것이 없다.

## 4. 팔 데를 임팩트 × 불확실성으로 고른다

| 가지 | 임팩트 | 불확실성 | 판정 |
|---|---|---|---|
| 감가상각 6년 가정 | 큼 | 큼 | ★ 먼저 판다 |
| 고객 신용(모델회사) | 큼 | 큼 | ★ 먼저 판다 |
| GPU 담보값 | 큼 | 중 | 다음 |
| 스팟 단가 | 중 | 큼 | 다음 |
| 전력 | 중 | 낮음 | 안 판다 |
| 원금·이자 조건 | 큼 | 낮음 | 계약서에 있다. 확인만 |

★ 둘이 이 물음의 승부처다. **둘 다 「자료가 많아서」 뽑힌 것이 아니라 「틀리면 결론이
뒤집혀서」 뽑혔다.** 자료량으로 골랐다면 둘 다 아래로 밀렸을 것이다.

## 5. 어긋난 데를 밝힌다

**MECE 가 안 맞는 자리.** 하이퍼스케일러와 네오클라우드가 겹친다. 하이퍼스케일러가
네오클라우드에서 빌려 쓰기도 하고 임대료를 대신 내주기도 한다. 그러면 「하이퍼스케일러는
잘라 냄」이 온전한 소거가 아니다. **겹치는 만큼 그 가지를 다시 봐야 한다.**

**가설이지 확인이 아닌 것.** 「네오클라우드가 문제다」는 세운 가설이다. 이 구조는 그
가설을 **깨거나 세우려고** 만든 것이지 이미 답을 아는 것이 아니다.
