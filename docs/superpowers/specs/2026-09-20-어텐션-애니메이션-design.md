# 어텐션 애니메이션 — 설계

2026-09-20 확정. 대화에서 어텐션·배칭·엔그램을 정지 도해로 설명하다가, 시간이 흐르는 계산은
정지 판으로는 안 잡힌다는 것이 드러나 애니메이션 장을 새로 세운다. 첫 편은 어텐션이다.

## 1. 무엇을 만드나

공개 대시보드에 새 장 하나. 어텐션 계산 **한 번**을 일곱 단계로 늦춰 보인다.
디코드 루프 전체나 실제 문장의 의미 해석은 이번 편이 아니다 — 뒤에 올 편들의 몫이다.

- 자리: `대시보드/애니메이션 — 어텐션.html`, `scripts/gen_site.py` PAGES 등록
- 독자: 뉴스를 따라가다 「어텐션이 뭔데」에서 막힌 사람
- 시리즈: 어텐션 → 배칭·연속 배칭 → 엔그램 조회 순으로 편이 쌓인다. 장 하나에 편 여럿

## 2. 재료 — 실제 값만 그린다

도해 규칙 1(원문에 없는 값을 그리지 않는다)을 이 장에서도 지킨다. 화면에 뜨는 점수는
손으로 지어내지 않고 실제 모델에서 뽑는다.

`scratchpad/attn_trace.py` 가 모델을 한 번 돌려 `data/attn_trace.json` 을 굽는다. 한 번 굽고
결과를 커밋한다 — 페이지가 뜰 때마다 모델을 돌리지 않는다.

- 모델: Qwen2.5-0.5B-Instruct (CPU, `output_attentions=True`). 한국어 토크나이저가 쓸 만하고
  포워드 한 번이 몇 초다
- 문장: 지시대명사가 앞 낱말을 되짚는 꼴. 초안은
  「어제 산 고양이 사료를 오늘 열었는데, 그것이 벌써 눅눅했다」이다. 토크나이즈한 결과가
  열두 토큰을 넘으면 문장을 줄여 다시 뽑는다 — 막대가 화면에 안 들어간다
- 보는 자리: 「그것이」 토큰
- 층·헤드: 전 층 전 헤드를 훑어 **그 자리가 앞 명사를 가장 세게 되짚는 헤드 하나**를 고른다.
  고른 근거(층 번호·헤드 번호·그때 가중치)를 JSON 과 화면 양쪽에 박는다

JSON 스키마:

```json
{
  "model": "Qwen/Qwen2.5-0.5B-Instruct",
  "sentence": "…",
  "tokens": ["어제", "산", …],
  "query_pos": 9,
  "layer": 14, "head": 7,          // 예시 — 실제 값은 트레이스 스크립트가 고른다
  "picked_by": "그 자리에서 앞 명사 토큰에 준 가중치가 가장 큰 헤드",
  "scores_raw": [ … ],        // 소프트맥스 전 내적값, 길이 = query_pos+1
  "scores_softmax": [ … ],    // 합 1
  "dim": 64,                  // 헤드 하나의 차원
  "q_preview": [ … ],         // Q 벡터 앞 8개 값 (화면에 숫자로 뜨는 것만)
  "k_preview": [[ … ]],       // 토큰별 K 앞 8개
  "v_preview": [[ … ]],       // 토큰별 V 앞 8개
  "out_preview": [ … ]        // 가중합 결과 앞 8개
}
```

`*_preview` 를 여덟 개로 자르는 이유는 화면에 64개를 다 못 쓰기 때문이다. 자른다는 사실을
화면에 적는다 — 「64개 중 앞 8개」.

## 3. 스텝 일곱

| # | 화면에서 바뀌는 것 | 설명 줄 |
|---|---|---|
| ① | 문장 줄이 뜨고 「그것이」 칸에 테두리 | 지금 이 자리에서 다음 토큰을 만든다 |
| ② | 그 칸에서 Q 상자가 내려온다 | 지금 토큰이 무엇을 찾는지가 Q다 |
| ③ | 앞선 토큰들 아래 K 칸이 한 줄로 깔린다 | 앞선 토큰마다 K가 이미 캐시에 있다 |
| ④ | Q가 K 칸을 왼쪽부터 하나씩 훑으며 막대가 자란다 | Q와 K를 곱해 점수를 낸다 (연속 애니메이션) |
| ⑤ | 막대가 합 1의 비율로 다시 그려진다 | 소프트맥스 — 점수를 비율로 바꾼다 |
| ⑥ | V 칸들이 그 비율만큼 아래로 흘러 섞인다 | 비율대로 V를 가중합한다 |
| ⑦ | 섞인 결과가 상자 하나로 남는다 | 이것이 이 자리의 어텐션 출력이다 |

④만 연속이고(토큰 하나당 0.35초로 훑는다) 나머지 여섯은 상태 전환이다. 설명 줄은 판 밖 한 줄이고, 판 위에 남는 글자는
토큰·값 라벨뿐이다(도해 규칙 3).

## 4. 엔진 — 스텝 상태 기계

- 페이지가 스텝 배열을 들고 있다. 스텝을 바꾸면 SVG 요소의 class·속성만 바뀌고
  그 사이는 CSS `transition` 이 메운다
- 자동재생은 그 위에 타이머로 스텝을 넘긴다. 들어오면 한 바퀴 돌고 멈춘다
- 「다음·이전」 버튼이 아무 때나 타이머를 끊고 그 스텝으로 간다
- 되돌리기가 공짜다 — 모든 스텝이 자기 정지 상태를 갖기 때문이다
- 바깥 라이브러리를 안 쓴다. 이 저장소 다른 장과 같다

## 5. 규약 — `gen_anim_page.py` 의 `check_ui()`

다섯을 본다. 어기면 생성기가 멈춘다.

1. 스텝 수와 설명 줄 수가 같다
2. 모든 스텝이 정지 상태를 갖는다 — 스텝 i마다 `data-step="i"` 일 때 보이는 요소 집합이
   CSS 에 정의돼 있고, 빠진 스텝이 없다
3. 화면에 뜬 숫자가 전부 `data/attn_trace.json` 에 있다 — 지어낸 값이 못 샌다
4. 자동재생을 멈출 수단이 화면에 있다
5. 가로 스크롤이 안 생긴다(모바일 폭 360에서도)

배치는 눈으로 안 본다. Playwright 로 스텝 일곱을 각각 찍어 `scratchpad/check_fig.py` 에 먹인다.

## 6. 화면 배치

위에서 아래로 넉 줄이다.

```
문장 줄      토큰마다 칸. 지금 보는 자리는 테두리
판           Q 상자 하나 · K 칸들 · V 칸들
점수 막대     토큰마다 세로 막대. ④에서 자라고 ⑤에서 비율로 다시 그려진다
바닥         설명 한 줄 + 「이전·다음·처음부터」 버튼
```

모바일(폭 360)에서는 판을 접고 문장 줄과 막대 줄만 남긴다. 색은 회색조,
지금 보는 자리와 방금 계산한 막대에만 강조색 하나.

## 7. 기존 것과의 관계

- `대시보드/개념 지도 — LLM 계층·병렬화.html` 은 그대로 둔다. 그 장은 구조를 한 판에 늘어놓고
  눌러 보는 꼴이라 시간이 없고, 이 장은 한 계산을 시간축에 푸는 꼴이다. 개념 지도의 어텐션
  모듈 패널에서 이 장으로 가는 링크 한 줄만 건다
- 대화에서 그린 정지 SVG(`fig_qkv2` 등)는 재료로 안 쓴다. 판의 꼴(Q·K·V 레인, 회색조,
  번호로 짚고 설명은 판 밖)만 물려받고 좌표는 실제 값에 맞춰 다시 잡는다

## 8. 파일

```
scratchpad/attn_trace.py            모델 한 번 돌려 값 굽기
data/attn_trace.json                구운 값 (커밋한다)
scratchpad/gen_anim_page.py         페이지 생성 + check_ui()
대시보드/애니메이션 — 어텐션.html      생성물. 손으로 안 고친다
docs/규칙 — 애니메이션.md            이 장의 규칙 (스텝·설명 줄·색·모바일·검사)
scripts/gen_site.py                 PAGES 에 한 줄
```

## 9. 안 하는 것

- 브라우저에서 모델을 돌리지 않는다. 값은 미리 구워 둔다
- 층·헤드를 독자가 고르게 하지 않는다. 첫 편은 헤드 하나만 본다
- 소리·자막·동영상 파일을 안 만든다. SVG와 CSS로 끝낸다
- 디코드 루프·엔그램은 이번 편이 아니다
