# AI 비즈니스 — 밸류체인 리포트 설계

정리일 2026-08-24. 산출물은 `대시보드/통합 보고서.html` 안의 세 번째 리포트다.
바탕은 SemiAnalysis 뉴스레터 변환본 30편(`content/newsletter/**`).

## 무엇을 묻나

**AI에서 번 돈은 층마다 누구에게 얼마나 남나.**

한 줄 사슬로 세우지 않는다. 모델 랩이 사는 것이 둘이라서다 — 컴퓨트와 데이터·환경.
한 줄로 그리면 RL 환경·데이터 파운드리 층이 낄 자리가 없다.

```
레일① 컴퓨트   전력 → 건설 → 냉각 → 칩(파운드리·HBM) → 서버/랙 → 네트워킹
                 → 클라우드(하이퍼스케일러·네오클라우드) → 추론 엔진(무료) → 추론 서빙 사업자(TaaS)
                                                                              ↘
레일② 데이터   인간 전문가 → RL 환경·데이터 파운드리 → 평가·검증               →  모델 랩 → 토큰 → 앱·에이전트 → 기업 예산
                                                                              ↗
레일③ 받는 법  장비 판매 / 임대 / 종량 / 구독 / 오프테이크·부채 백스톱  (레일①②를 가로지른다)
```

층마다 같은 넷을 묻는다: **누가 파나 / 값이 어떻게 정해지나 / 마진이 어디 있나 / 무엇이 그 마진을 깎나.**

## 생성기

`scratchpad/gen_report_dashboard.py` 하나. 그림은 원본 대시보드 생성기에서 import 한다.

`dash_common.render()` 는 카드 없는 층(`top=`)을 하나만 받는다. 지금 그 자리에 로봇 보고서 둘이
들어 있어, 성격이 다른 이 리포트를 같은 타일에 넣으면 타일 이름이 내용과 어긋난다.
`render()` 에 `tops=[(id, 제목, 설명, 편수, html), …]` 를 더한다 — 기존 `top=` 인자는 그대로 둔다.
