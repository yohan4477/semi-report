## 브리프에서 고친 것

**① JS 가 고립 표시를 지웠다.** 뼈대의 `paint()` 는
`el.classList.toggle('faint', okK && !okO && !!org)` 로 조직 거르개를 칠했다. `faint`
는 생성 때 「아무 데도 안 걸린 주장」에 박아 둔 클래스라, 조직을 한 번 누르는 순간
50줄의 고립 표시가 통째로 지워지고 다시 안 돌아온다. 클래스를 둘로 갈랐다 — 생성 때
박히는 `faint`(고립)와 누를 때마다 붙었다 떨어지는 `off`(조직 거르개). CSS 는 둘 다
같은 회색으로 옅게 낸다. 이유는 파일 머리 주석에 적었다.

**② `document.querySelectorAll(...).forEach`** 를 `[].forEach.call(...)` 로 바꿨다.
`NodeList.prototype.forEach` 를 안 가진 브라우저에서 거르개가 통째로 죽는데, 죽어도
화면은 멀쩡해 보여서 눈으로는 안 걸린다. 뼈대는 위쪽 `rows` 는 이미
`[].slice.call` 로 감싸 놓고 아래 둘만 안 감쌌다.

**③ `title_of` 에 기억(`_TITLES`)을 붙였다.** 줄마다 `md_lines()` 를 불러 발표
변환본 전문을 다시 읽었다 — 126번 읽던 것이 66번이 됐다. 값은 안 바뀐다.

**④ CSS 셋.** `grid-template-columns` 의 `1fr` → `minmax(0,1fr)`, `body` 에
`word-break:keep-all; overflow-wrap:anywhere`. 390px 에서 긴 영문 토큰 하나가 격자
칸을 밀어 가로 스크롤을 내는 자리를 막는다. `.row.off .mark/.tie` 에 `opacity:.45`.

**⑤ 앞머리 한 문장.** lede 에 「아무 데도 안 걸린 주장은 옅게 뒀다」를 더했다.
40%가 옅은데 왜 옅은지가 화면에 안 적혀 있었다.

색(`#555` 등 회색)은 브리프 그대로 뒀다.

## 걱정

- **고립 40% 는 재료 쪽 문제다.** 화면은 그것을 숨기지 않고 옅게 드러내지만, 절반
  가까운 줄이 아무 데도 안 걸린 채 시간순으로만 놓여 있으면 「흐름」이라기보다
  목록에 가깝게 읽힐 수 있다. 관계를 더 캐는 일은 재료 과제의 몫이다.
- **엇갈림이 5건뿐이다.** 점선 상자가 다섯 번밖에 안 나와서 「엇갈림만」 거르개를
  누르면 다섯 줄만 남는다. 거르개가 있을 값어치는 있지만 지금 분량으로는 허전하다.
- **조직 거르개 14개**가 sticky 줄에 다 늘어선다. 390px 에서 세 줄쯤 차지해 본문이
  그만큼 밀린다. 눈으로 볼 때 이 자리를 같이 봐 달라.
- 이 장은 아직 `AI Engineer 대시보드.html` 쪽에서 들어오는 링크가 없다 — 되돌아가는
  링크만 있고 들어오는 길은 없다. 붙일지는 별도 판단.
