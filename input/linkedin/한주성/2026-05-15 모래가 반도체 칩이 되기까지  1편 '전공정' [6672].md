<모래가 반도체 칩이 되기까지: 1편 '전공정'>

코스피가 어느덧 8,000 문턱에 왔습니다.
반도체 슈퍼사이클로 삼성전자·SK하이닉스가 코스피 시총의 절반입니다.

근데 솔직히,
"반도체 칩이 어떤 과정을 거쳐 탄생하는지" 아는 분은 많지 않습니다. 

그래서 오늘 콘텐츠를 준비했습니다. 

-----
Q. 반도체, 뭐로 만들어요?
A. 모래입니다.

모래 속 실리콘을 뽑아내서 정제하면
커다란 실리콘 덩어리가 됩니다.
이걸 얇게 썰면 동그란 판 — aka 웨이퍼.
반도체를 만드는 도화지입니다.

이 도화지 한 장(지름 30cm)에서
칩 수백~수천 개가 동시에 만들어집니다.

📌 한국 회사
→ SK실트론 — 세계 3위 웨이퍼 제조사

-----
<전공정 vs 후공정>

전공정 — 웨이퍼에 회로를 그리는 것
후공정 — 잘라서 포장하는 것

오늘은 전공정만 다룹니다.

-----
<전공정: 4단계가 수백 번 반복됩니다>

① 닦는다 (세정)

매 공정이 끝날 때마다 반복되는
약방의 감초 같은 공정입니다.
먼지 한 톨도 불량의 원인이 됩니다.

📌 한국 회사
→ 솔브레인 — 세정액·식각액 국내 1위
→ 한솔케미칼 — 고순도 과산화수소
→ 제우스 — 습식 세정 장비
→ 엘오티베큠 — 공정용 진공펌프 국내 1위

② 입힌다 (증착)

웨이퍼 위에 머리카락 1만분의 1 두께의
얇은 막을 입힙니다. 이 막이 회로가 됩니다.

📌 한국 회사 (장비)
→ 주성엔지니어링 — CVD·ALD 장비
→ 원익IPS, 유진테크, 테스 — CVD·ALD 장비
→ HPSP — 고압 수소 어닐링 장비 세계 독점

📌 한국 회사 (소재)
→ 원익머트리얼즈, 후성 — 공정가스
→ 디엔에프, 레이크머티리얼즈 — ALD 전구체

③ 그린다 (포토리소그래피)

감광액 도포 → 빛으로 회로 찍기 → 현상.

여기 쓰는 노광장비는 네덜란드 ASML만 만듭니다.
한 대에 수천억 원.

📌 한국 회사
→ 동진쎄미켐 — 감광액(KrF급)
→ 에스앤에스텍 — EUV 블랭크마스크
→ FST(에프에스티) — 마스크 보호 덮개(펠리클)
→ 피에스케이 — 감광액 제거 장비

④ 깎는다 (식각)

필요 없는 부분을 식각액·플라즈마로 깎아냅니다.
깎고 나면 다시 ①세정으로 돌아갑니다.

📌 한국 회사
→ 솔브레인, 이엔에프테크놀로지 — 식각액
→ 티씨케이(TCK) — SiC 링 세계 1위 (핵심 소모품)
→ 하나머티리얼즈 — 식각용 실리콘 전극·링

+ 갈아준다 (CMP)

층을 쌓을 때마다 표면을 평평하게 연마합니다.

📌 한국 회사
→ 케이씨텍 — CMP 슬러리·장비
→ 솔브레인 — CMP 슬러리

+ 재보고 검사한다 (계측·검사)

나노미터 수준의 오차를 매 공정마다 잡아냅니다.

📌 한국 회사
→ 이오테크닉스 — 레이저 계측 장비
→ 오로스테크놀로지 — OCD 광계측 장비
→ 파크시스템스 — 원자현미경(AFM) 세계 1위
→ 리노공업 — 반도체 검사핀(리노핀) 세계 1위

-----
삼성·하이닉스가 투자를 늘릴수록
장비·소재·부품 회사들이 같이 웃습니다.

기계를 사고 → 장비 회사 수주
재료를 사고 → 소재 회사 수주
소모품을 교체하며 → 부품 회사 반복 매출
