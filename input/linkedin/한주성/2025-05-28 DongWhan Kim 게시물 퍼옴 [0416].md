1000개의 맥킨지 장표를 분석한 Chat GPT 가 알려준 과제 전형 전략

Front office, Back office 할 것 없이 과제 전형을 진행하는 회사들이 점점 많아지네요. 
부담스러운 전형인 것은 맞습니다. 
하지만 경험과 인사이트를 한 번씩 정리해 놓으면, 
다른 채용 전형, 내부/외부 강의 기회 등 언제 어떤 기회에 활용될지 모르니 
그런 계기로 접근하는 것이 마음 편하실 것 같다는 생각입니다. 

slidestart.com 이라는 웹사이트를 아시나요? 

MBB 부터 글로벌 기업의 장표들을 볼 수 있는 곳 입니다. 
이 곳에서 1000 개의 맥킨지 앤 컴퍼니 장표를 다운 받아 chat gpt 에 데이터로 올린 후 얻은 
슬라이드 작성 전략을 요약한 유튜브 영상이 있어 핵심 내용을 공유 드립니다.

🎯 슬라이드 제목은 결론이어야 한다

맥킨지는 슬라이드 제목을 단순한 섹션 이름이 아닌 ‘결론문’으로 씁니다.

전체 슬라이드의 72%는 능동태, 평균 영문 14단어 - 국문 장표 데이터는 없네요ㅠ- 내외의 결과 지향적 제목
→ 발표자의 메시지가 더 명확히 전달되고, 흐름이 자연스럽게 이어집니다.


🧩 슬라이드당 하나의 메시지 원칙

맥킨지의 슬라이드 62~76%는 명확한 핵심 메시지 하나에 집중
→ 정보를 쪼개어 슬라이드를 나누고, 한 번에 하나의 메시지만 전달하도록 설계


📊 복잡하지 않은 시각 자료

슬라이드당 평균 텍스트는 약 100단어

불필요한 시각적 요소 배제, 하나의 차트 중심 구성
→ 발표 흐름 집중도와 이해도를 동시에 향상


🔄 4가지 슬라이드 레이아웃이 전체의 70%

반복적 구조: (1) 단일 차트 (2) 차트 + 불렛포인트 (3) 2열 비교 (4) 테이블
→ 시각적 통일성과 이해도 향상, 다양한 데이터를 안정적으로 전달


📈 가장 많이 쓰인 차트 유형은 Bar Chart (40%)

비교에 탁월한 시각적 수단

그 외 트렌드 분석용 line chart, waterfall chart 등도 적절히 배치


🎨 색상은 최소화하고 메시지 강조에만 사용

색은 핵심 메시지 구분에만 제한적으로 사용
→ 군더더기 없는 프로페셔널한 인상, 정보 전달 집중도 극대화


🗂 Top-down 커뮤니케이션 구조

제목 → 부제목 → 영역 분할 구조로 시각적 흐름 구성
→ 발표자가 이야기하는 순서대로 청중이 따라갈 수 있도록 설계

구직자 여러분의 경험과 인사이트가 형식에 손해보지 않기를 응원드립니다.
