# 도해 그리기

카드 도해는 `scripts/card_lib.py`의 `figs`로 들어가는 **인라인 SVG**다. 외부 이미지도 PPT도 쓰지 않는다 — 다크모드에서 색이 따라 뒤집혀야 하고, 원본을 고치면 다시 생성돼야 하고, 글자가 벡터여야 확대해도 안 흐려진다.

`figs = [(anchor, 제목, svg, 캡션)]`. anchor는 몇 번째 슬림 포인트 뒤에 세울지다(0이면 포인트 앞).

## 반드시 지킬 것 넷

### 1. 원문에 없는 값을 그리지 않는다 — 도형 개수도 값이다

가장 자주 깨지고 가장 티가 안 나는 규칙이다. **막대 높이·계단·아이콘 개수는 전부 수치로 읽힌다.** 원문에 그 수가 없으면 그리지 말고 다른 표현으로 바꾼다.

```
✕ 회차별 물량이 원문에 없는데 계단 막대를 그렸다 → 눈은 수치로 읽고 근거는 없다
✕ 「못 나오는 배」를 열 척, 「밖에 남은 배」를 세 척 그렸다 → 원문엔 35척·100척뿐이다
✓ 높이를 없애고 상태 둘로 바꾼다 — 회색은 돈이 안 들어오는 구간, 강조색은 들어오는 구간
✓ 셀 수 없으면 세지 않는다. 「몇 척뿐」은 글자로 적고 아이콘은 하나만 둔다
```

라벨에 숫자를 안 썼다고 빠져나가지 못한다. **개수와 길이와 높이가 이미 주장이다.**

그린 뒤 기계로 확인한다. 그림 글자에서 숫자를 뽑아 원문에 있는지 전수 대조한다.

```bash
PYTHONIOENCODING=utf-8 python -c "
import io,re,sys
svg, src = io.open(sys.argv[1],encoding='utf-8').read(), io.open(sys.argv[2],encoding='utf-8').read()
srcn = re.sub(r'[\s,]','',src)
nums = {n for s in re.findall(r'<text[^>]*>([^<]*)<', svg) for n in re.findall(r'\d[\d,\.]*', s)}
miss = [n for n in nums if len(n.replace(',','')) >= 2 and n.replace(',','') not in srcn]
print('못 찾은 값:', miss or '없음')
" <도해가 든 파일> <원문 md>
```

이 대조는 **글자에 적힌 값만** 본다. 도형 개수는 사람이 세야 한다 — 같은 모양이 여러 개면 그 개수가 원문에 있는 수인지 묻는다.

### 2. 좌표는 사람이 찍지 않는다

지도·도식의 자리를 손으로 어림하면 반드시 어긋난다. 굽는 쪽에서 계산해 내보내고 그림은 그 값만 쓴다.

| 필요한 것 | 쓰는 것 |
|---|---|
| 미국 주 경계·주별 한가운데 | `data/us_lower48_albers.json` (`scripts/make_us_map_path.py`) |
| 세계 나라 경계·나라별 한가운데·위경도 앵커 | `data/world_robinson.json` (`scripts/make_world_map_path.py`) |
| 시간축 위 어느 달의 x좌표 | 개월 수를 받는 함수 하나를 두고 그것만 부른다 |

지시선 끝도 손으로 찍지 않는다. 내보낸 한가운데 좌표를 그대로 건다.

### 3. 그림 판 위에 글자를 얹지 않는다

지도든 도식이든 **판 위에는 그림만** 둔다. 무엇이 무슨 색인지는 판 아래 범례가 말하고, 판단은 그 아래 상자가 말한다. 상자 안에 든 글자는 판 위가 아니다 — 그건 괜찮다.

지도에 얹은 설명은 배경과 겹쳐 안 읽힌다. 색 딱지 하나와 한 줄로 내린다.

### 4. 배치는 눈이 아니라 검사기가 본다

```bash
PYTHONIOENCODING=utf-8 python scratchpad/check_fig.py          # 전체
PYTHONIOENCODING=utf-8 python scratchpad/check_fig.py 세계지도   # 제목에 그 말이 든 것만
```

글자끼리 겹침 · 선에 깔림 · 가로 넘침 · 세로 넘침 넷을 센다. `build_all.py`도 이걸 돌린다. **눈으로 보고 「안 겹친다」고 보고하지 않는다** — 그렇게 두 번 틀렸다.

아직 카드에 안 붙인 도해는 `main()`이 못 본다. 그럴 때는 `hits()`를 직접 부른다.

```python
import sys; sys.path.insert(0, 'scratchpad')
import check_fig; print(check_fig.hits(FIG) or 'FAIL 0건')
```

검사기는 배치만 본다. 규칙 1은 못 잡는다.

## 화살표

`.flow`는 1.6px 회색이라 지도 위에서 지시선과 구분이 안 된다. 지도에 쓸 화살표는 그림 안에 마커를 따로 두고 강조색으로 낸다(마커 id는 그림마다 다르게 — 한 페이지에 여럿이 선다).

미리보기 HTML을 따로 만들 때 `card_lib.FIG_DEFS`를 빠뜨리면 **화살표 머리가 안 그려진다.** 선만 남아 방향을 잃는다.

## 무엇을 그릴지 고르기

한 그림은 하나만 말한다. 축이 둘이면 그림을 둘로 나눈다.

| 보이려는 것 | 형태 |
|---|---|
| 어디냐가 내용이다 | 지도. 주·나라를 통째로 칠한다(점 찍기보다 어긋날 여지가 없다) |
| 방향이 뒤집혔다 | 같은 지도 둘, 화살표만 반대로. 양 끝을 고정해 실제로 반대를 가리키게 |
| 순서가 내용이다 | 줄마다 상대·손에 든 것·받아 낸 것. 받아 낸 것이 다음 줄 손에 드는 것이 되게 잇는다 |
| 누가 누구에게 무엇을 주나 | 흐름도. 주체 셋 이상·오가는 것 두 종류 이상일 때만. 판 고르기·선 세 종류·역할 도랑은 `docs/흐름도 — 만드는 규칙.md` |
| 언제냐가 내용이다 | 시간축 하나에 상태 둘. 높이는 쓰지 않는다 |
| 조건과 결과가 어긋난다 | 좌우 대비. 한쪽을 조건까지 나쁘게 그리지 않는다 — 「좋은 데가 졌다」가 요점이다 |

## 자주 나는 사고

| 증상 | 원인 | 처방 |
|---|---|---|
| 「너무 허접해」 | 없는 값을 그렸다. 다듬어도 안 낫는다 | 규칙 1 |
| 「그림과 표시가 안 맞아」 | 좌표를 손으로 찍었다 | 규칙 2 |
| 「글자가 안 보여」 | 판 위에 얹었다 | 규칙 3 |
| 「글자랑 화살표 겹쳐」 | 눈으로 봤다 | 규칙 4 |
| 「방향을 모르겠어」 | 마커가 없거나 선이 얇고 회색이다 | 화살표 절 |
| 「도해 봐도 이해가 안 가」 | 상자만 나열했다. 무엇을 주고 무엇을 받는지가 없다 | 형태 표 |

## 마치기 전

- [ ] 그림에 든 값을 하나씩 원문에서 찾았나. 도형 개수도 값이다
- [ ] 좌표를 손으로 찍은 자리가 남았나
- [ ] 판 위에 글자가 남았나
- [ ] `check_fig.py` FAIL 0인가
- [ ] 그림이 원문보다 세게 주장하지 않나 (실패 사례가 있으면 같이 그린다)
